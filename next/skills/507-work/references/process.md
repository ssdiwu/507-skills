# 工作事项与过程记录

工作中的实质变化按[工作记录](shared/work-records.md)主动保存；本参考只补业务事项的对象和状态，不重复维护通用记录方法。局部更新沿原事项处理，不要求建立整套工作日志。

先定位任务系统、原工单或清单的稳定身份、当前字段及消息时间基准。正式截止、提醒、事件、责任、接受和发布分别维护；团队交付不等于个人已完成，拟议状态不等于平台已更新。当前记录回链原事项，平台写入须具体授权并读回，不能用本地过程记录覆盖正式状态。

目标负责人或指定整合者维护共享当前快照；独立分工先按[协调方法](shared/task-coordination.md)核写权与结果接收。真实转交采用[续办方法](shared/continuation.md)，交接只引用已保存依据和未持久化缺口。
