# 产品界面组件查找与抽取

把页面或功能需要的界面块接到这个产品真实可用的组件库，减少调用处重复实现同一件事。结果是已有组件的采用，或库内新组件与调用处的迁移；这不是整体界面设计入口，也不是技能共有方法、脚本的编写工作。

## 输入与修改权

承接即将实现或已经重复的界面块、目标产品及当前版本、真实组件库和已有调用处，以及原任务的授权。先核对用户改动、项目规范、组件归属和唯一写入者；只查找或只读请求不修改组件、调用者、依赖或库配置。

原任务已授权实施时，可在相应范围内修改库组件、必要导出、调用处及直接相关检查／说明。识别可读的第三方库与可写的产品组件位置，不在依赖安装目录改第三方源码。未授权的库或调用处具体交回，不因被委托而取得全库重构权。不安装或更换组件库，不顺带重做页面、建立新设计系统、修改业务权限或改变数据通路。未能确定真实库、写入范围或有效版本时，保留未知和最小所需前提；原页面不依赖该缺口的工作可继续。

## 先找现有组件，再决定结果

在目标产品已有的组件清单、导出入口、当前版本源码／类型和实际用法中查找。按输入、状态、操作、样式约束和可访问性判断能否采用；同名目录、截图或相似外观不是可用证据。查找限于当前块及相关库，不扫描或安装无关库。版本和出处影响判断时读[事实与来源](references/shared/evidence.md)。

| 已核事实 | 本次结果 |
| --- | --- |
| 库内已有适用组件 | 复用它，在授权内将相关调用接过去；核对真实导出、必要参数和调用结果，不再造一份替代组件 |
| 库内没有；同一块有多个已存在或已确认即将实现的使用位置 | 将稳定共同部分做成库组件，按这个产品的组织与导出约定落位，并把范围内已写的地方改用它 |
| 库内没有；只有一处使用 | 留在原地，说明查找范围和没有采用／抽取的依据；不为可能的未来调用提前造库组件 |
| 当前库或调用关系不可核实，或只获查找权限 | 交可定位的发现、未知和受阻部分；不把未查到当不存在，不把建议写成已经接入 |

“同一块”需要共同语义和真实使用关系，不能只因外观相似强行合并。使用位置来自现有调用或已确认安排，不能编造未来消费者来满足抽取条件。库已存在但缺一个组件，与整个组件库尚未建立分别处理。

## 抽取并迁移已写调用

采用目标产品已有的目录、命名、导出和组件组织方式。共同组件只承载可复用的呈现与交互接口；业务对象、权限判断、数据读取和写入仍沿原所有者。保留调用处真正需要的输入、回调和差异，不加入没有消费者的配置，避免只搬代码却留下重复状态或手工协调。

改调用前核对既有公开行为、参数／默认值、回调时机、状态所有权，以及本次实际影响的键盘、焦点、草稿和生命周期。迁移需要保持行为时读[行为不变修改](references/shared/behavior-preserving-change.md)，用已有基线检查受影响的旧调用与已确认的新使用路径。完成导出和引用切换后，才能清理范围内无消费者的重复实现；未授权或未迁移的使用位置保持可查，不能称全量迁移完成。

产品操作、状态、反馈和完整用户路径仍由原页面／功能的实施职责持有；抽组件不重新定义它们。发现必须改变业务行为的差异时返回原任务，不以组件抽取冒充需求变更。

## 验证、完成与返回

按实际改动核对组件位置、可用导出、输入／回调及每个受影响调用处；运行产品已有的相称检查。必要操作验证回到真实页面和原动作，静态引用或构建通过不代替它。如何观察结果需要展开时读[可观察验收](references/shared/validation.md)。只查找或单处保留时，以查找证据和明确去向完成，不要求产出代码或新增测试。

交付找到并采用的组件，或新增组件、导出和已迁移调用；单处保留／只读则交对应位置、查找范围与判断。说明本次完成情况、实际验证、未覆盖和仍未迁移处。行为或公开接口变化按项目要求由另一执行者独立审查；组件存在不证明所有页面、人的体验或发布已通过。

结果需要接续时按[权威与返回](references/shared/authority-and-return.md)回到原页面或功能。原目标仍有授权工作时继续；用户只要求本次查找／抽取时结束，不自动扩成整份界面交付，也不要求先走主要技能。验证失败保留原可用实现、失败信号与回退点，只暂停依赖该问题的迁移。
