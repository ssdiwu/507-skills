# 行为与验收规格

将已确认目标写成后续执行者和验收者可直接使用的行为依据。优先维护项目已有 spec；轻改只改必要条目，不强制建立完整 PRD（产品需求文档）或工单。

## 输入与修改范围

承接请求、指定版本、用户改稿、现行要求、项目术语及已确认取舍。只改授权的规格、直接相关导航和必要来源链接，不自行改生产代码、测试或远程工单。规格任务不自动取得实施权限；父任务已经授权实施时，规格完成后将依据返回并继续该目标。

先区分已确认要求、当前实现和实际验收。实现缺口不构成删减要求的理由；旧计划、未勾选项或历史候选不能直接变成现行需求。新旧目标实质冲突才处理用户取舍，可查事实自行核对，不重做访谈。

## 写成可执行依据

找到同一功能的当前正文，核对有效条件与来源后原位更新。需要迁移时先准备候选，验证要求保全和直接消费者，再切换引用并退出旧正文维护；超出授权的旧文件保持可用并报告最小缺口。一次性 PRD 按用户指定位置交付，并注明其是否成为项目权威。

规格描述角色、触发条件、操作或公开调用、成功／失败结果、范围与明确排除，保留会约束行为的身份、数据、兼容、权限及恢复条件。实现文件、内部拆分与具体测试代码由实施者决定；只有它们实际约束公开契约时才进入规格。

从项目已有用户路径或公开接缝选择验收，写清什么观察会拒绝错误结果。跨入口、状态、失败或恢复差异改变验收时，读[行为边界](references/behavior-boundaries.md)裁剪必要场景；材料已充分时直接沿用。验收计划与已执行结果分开保存，不把清单勾选当运行证据。

承接多轮确认时对账本次最终目标与最后有效修订；完整交付的验收说明组合关系和返回路径，不能仅列各局部模块。局部请求保持原范围，素材缺失与目标未实现分别记录。

要求完整首次使用或跨入口交付时，沿[工程证据](references/shared/engineering-evidence.md)区分目标动作与允许的测试准备：目标包含的绑定、配置或确认等动作不能被夹具预置后仍记为已覆盖。只验SDK／已准备中段时写清该起点，保留有效切片，不擅自扩成全流程或缩掉原完整要求。

## 与清理、重构接力

用户要求先把功能整理清楚再完整重构时，按指定范围形成现行功能与验收基准，覆盖实际入口、成功／失败、状态与数据、权限、兼容及恢复；规格条目可定位到来源、实现依据和拟验证信号。完整性以本次范围及真实消费者为准，当前实现、有效要求和已验证结果分别表达，不把现存缺陷写成应有行为。

规格已足够且父任务已授权行为不变重构时，将当前正文、范围、不变量、验收和未决项交给 `507-clean` 的清理职责，随后继续原目标；只要求整理规格时交付后结束，不自动改代码。涉及新增功能或修复既定行为的实施仍按相应工程目标处理，不以清理承接行为变更。

clean 发现缺失、过时或冲突条目时，承接具体清理项与证据，在原规格和原授权内校准；只读发现只交差距。有效要求与实现相反时保全要求并标出实现差距，需要用户决定的语义冲突只阻断相关项。依据补齐后返回原清理项，已有充分正文直接沿用，不在两入口间重复成文、确认或循环转交；另一技能不可用时按同一职责直接承接。

## 按需依据

| 条件 | 读取与用途 |
| --- | --- |
| 当前版本、原需求或来源归属不清 | [事实与来源](references/shared/evidence.md)：确认被承接的原件和覆盖 |
| 新修订、迁移或有效条件需要保全 | [权威与返回](references/shared/authority-and-return.md)：对账条目并确定唯一正文 |
| 目标、成本或责任仍有实质取舍 | [决定归属](references/shared/decision-ownership.md)：只交回用户拥有的选择 |
| 有阻塞行为定义的信息缺口 | [问题依赖](references/shared/question-frontier.md)：只解决会改变定稿的前提 |
| 验收能否区分正确结果仍不清 | [可观察验收](references/shared/validation.md)：选择代表性错误及验证层级 |
| 接受现有运行结果或状态／异步行为作依据 | [工程证据](references/shared/engineering-evidence.md)：区分要求、源码与实际原动作证据 |

## 完成与返回

完成时，需求、范围、条件和验收没有冲突，阻塞取舍已解决，授权范围只有一份当前正文，相关导航和来源可用。交付规格差异、未涉及范围与验证状态。只要求规格时结束；已有实施目标时返回当前基准，由实施者继续，不让用户选择下一技能。

关键行为无法唯一解释时保留原有效要求，标明未决及其阻塞动作；继续明确部分。事实、权限或来源不足的候选不定稿，不以空章节或待定占位伪装完成。

本次出现真实中断、上下文压缩或转交时核实际版本、写权、有效尝试与未完成；普通结束跳过时，读[真实中断、交接与续办](references/shared/continuation.md)并在本职责原权限与完成边界内采用。

本次目标需要对齐产品功能、入口与用户操作的设计／实现／运行差距时，读[交互点与证据](references/shared/interaction-map.md)。需要独立的可探索地图结果可按原权限委托 `507-product-map`；普通策略、规格或审查不强制建图，结果回到当前职责。
