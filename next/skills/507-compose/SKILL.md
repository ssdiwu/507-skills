# 组织、成文与修订

承担完整内容工作，交付可通读、可讲述或可推动下一动作的正文。目标、作者主张和材料已经充分时直接写，不重复总体规划、不要求先创建创意卡或走完整素材链。

## 输入、权限与范围

承接指定版本、用户手改、已确认目的、作者主张、受众、材料和修改授权。只读建议交付建议；局部润色保留原意、论据、推进关系与节奏，不扩大为整稿重写。完整成文或结构重写按实际授权完成；改变作者主张、承诺或风险超出范围时，先完成可独立的工作并带具体取舍返回。

用户已排除的方向退出当前内容，不能为了显得周全补回。第一人称经历、数字、引语、角色和责任来自材料；不制造作者声音。不因成文取得账号登录、消息发送、付费生成、知识库写入、提交或发布权限。

## 按当前内容工作选择方法

| 当前内容目标 | 采用方法与结果 |
| --- | --- |
| 文章、文案、结构重写或指定范围表达润色 | [书面成文](references/prose.md)：完整主稿或精确修订 |
| 活动、培训、合作或项目正式方案 | [方案成文](references/proposal.md)：让特定读者能够决定和行动；软件行为规格另有职责 |
| 演讲、课程、旁白或逐页内容 | [现场内容](references/spoken.md)：可听内容、页面正文与备注职责清楚；不自动生成音频或成片 |

仅读适用方法。作者和来源混杂、关键事实或引语需要核对时，读[作者与来源](references/shared/author-and-source.md)。修订有效版本、保护含义、多个载体同步或交付状态判断时，读[作品合同](references/shared/artifact-contract.md)。作者主张、说话位置或关键材料仍不足时，列明影响哪处表达并返回内容负责人；可查事实先查，有效信息与原授权继续承接。

先完成一版整体成立的内容，再核对材料承重、读者承诺、段落接力、作者声音与事实边界；用户明确要求逐节共创才按该方式反馈。作者声音从已允许使用的实际作品和明确纠正提炼，不把协作口癖、偶然错字或情绪复制成风格。

修订先重读当前稿，保留用户手改。局部事实只改直接依赖处；主线或因果的已授权改变检查受影响全文，同步本次实际承载文字的内容包、备注和已请求载体，不制造同题平行主稿。

需要中文书面或口播提醒时运行[书面检查器](scripts/check_prose.py)或[口播检查器](scripts/check_spoken.py)，先读[检查器边界](references/shared/text-checks.md)。两者只读、使用 Python 3.10+ 标准库，退出码成功只表示运行结束；发现须按语境处理，不能作为作者接受或事实验收。

用户还要求离线 HTML 且内容成熟时，读[呈现合同](references/shared/artifact-rendering.md)，使用[呈现脚本](scripts/render_artifact.py)制作图卡式页面、幻灯片或阅读网站，并看最终 HTML。真实内容还需确定视觉阅读关系时采用[设计提示](references/shared/artifact-prompts.md)。目标是图片、PPTX 或视频时，复用真实可用成熟工具核对依赖及目标文件；缺工具交付内容包和具体依赖，不能称目标载体已完成。

## 完成与接力

- **完成**：指定范围的内容已经完整交付，主张、材料、事实、责任和声音一致；局部修订保持原意，草稿与未决明确；适用的通读、朗读或检查已完成，范围与证据可辨。
- **返回**：交付主稿、方案、现场内容包或修订与必要说明。成熟内容需换受众或载体时进入适配工作；父目标还要求呈现则继续已有授权，不在内容完成时提前结束。仅需正文时结束，不自动发布。
- **恢复**：材料只支持较小范围时收窄或缩短；关键作者主张、事实或责任未成立时保留有效稿与具体缺口。新产物验证失败保留上一可用版；相邻技能缺失时依同边界直接做，不构造安装依赖。

本次出现已成熟内容还需要视觉方向选择时，读[视觉方向与真实反馈](references/shared/visual-direction.md)并在本职责原权限与完成边界内采用。

本次出现真实中断、上下文压缩或转交时核实际版本、写权、有效尝试与未完成；普通结束跳过时，读[真实中断、交接与续办](references/shared/continuation.md)并在本职责原权限与完成边界内采用。

本次出现当前稿具体表达缺口需要作者材料，既有材料足够时跳过时，读[显化作者一手材料](references/shared/author-interview.md)并在本职责原权限与完成边界内采用。

本次出现解释型作品确有读者旧解释需要校准时，读[同一场景的解释检验](references/shared/explanation-progression.md)并在本职责原权限与完成边界内采用。

本次出现旁白或分镜须交接给真实媒体制作时，读[媒体版本、时间与验收](references/shared/media-production.md)并在本职责原权限与完成边界内采用。

实际目标为图片、可编辑幻灯片或媒体时，读[真实载体适配](references/shared/media-adapters.md)，复用当前成熟工具；需要实物身份时按[文件回执](references/shared/artifact-receipt.md)使用[组件](scripts/artifact_receipt.py)。文件回执不裁决渲染、语义、许可或接受。

中文密页、图表或视觉关系需要展开时，读[视觉语义与中文呈现](references/shared/target-design.md)，保护实际内容关系与当前目标文件。

明确传播目标或标题优化请求时，读[标题与正文兑现](references/shared/title-promises.md)；普通文档不因载体名称启动增长任务。
