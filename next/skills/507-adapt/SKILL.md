# 成稿受众与载体适配

作为主要技能，把已经成立的内容变成目标读者能读、看或听的版本，负责本次适配范围和实际交付。用户可从本入口表达目标，Agent也可按需采用并把结果用于原任务。主张、材料和内容足够时直接沿指定版本处理，不重走采访或规划；适配改变受众入口、表达、信息安排、容量与呈现，保留作者判断与事实依据。

## 与成文和材料工作的分工

| 当前需要 | 采用方式 |
| --- | --- |
| 成熟内容换受众、场景或载体 | 本技能直接完成；为让目标读者理解而大幅改写措辞仍属适配，不按改字数量分工 |
| 重新决定主张、论证或作者叙事，或只润色当前稿件的局部文字 | 由create承接成文与修订；仅一部分需要重新判断时只处理该部分，结果返回原任务 |
| 材料混杂，身份、来源、去重或支持范围值得独立整理 | 按需采用material；普通查一条参考可直接完成，不把材料整理变成必经步骤 |

已有目标、设计和用户修订继续有效。局部适配只改约定范围；采用相邻能力不重新确认同一请求，也不结束尚未完成的原交付。

## 输入、权限与产物

承接成熟稿、指定版本与手改、目标受众、载体、保留要求和修改授权。按[作品合同](references/shared/artifact-contract.md)确定当前内容版本、保护项及派生位置，不回写唯一主稿除非本次授权覆盖。只读建议仍只交建议；有制作请求时完成目标环境中可用的内容和呈现实物。

产物是保义派生稿或内容包，以及实际请求且工具可实现的目标文件、来源映射和检查结果。文章、可见页面、口播与备注各保留必要信息；摘要须有明确提炼请求，不因“图卡”默认删正文。素材许可、账号登录、消息发送、付费生成、安装、提交与发布仍按原授权，不由适配取得。

## 受众入口与载体容量

成熟作品要改变阅读或听觉方式时使用。先从读者已有知识、当前困境、使用场景与需要采取的动作判断理解缺口，不把换平台等同于增长或重新写主张。

| 目标 | 内容安排 | 必须保留的边界 |
| --- | --- | --- |
| 文章与平台文字 | 调整入口、层级、长度与相关性；复用原稿判断与材料 | 来源、关键论据、条件与作者声音；改标题不能新增成绩或承诺 |
| 图卡式阅读 | 默认按完整内容与顺序分配页面；明确提炼时才选摘要 | 全文模式不丢可见正文；摘要说明重要未入选内容去向；HTML 不是已导出图片 |
| 幻灯片 | 每页完成认知任务；观众文字、讲者备注与会说出口的稿件分工 | 页面标题保留含义；必要素材真实存在；逐页稿不是已生成 PPTX |
| 阅读网站 | 围绕寻找、阅读、比较、来源与返回安排内容 | 展开或点击不执行源流程；状态与来源不因选中而变成完成 |
| 口播与旁白 | 给耳朵重排节奏，明确段任务、发音与必要画面证据 | 操作必要数字、条件与限制不丢；估时不是实际音频时长；内容包不是配音或成片 |

压缩先去重复、制作旁白与对读者无帮助的过程信息；保留支撑中心判断的依据。把重要事实挪到读者看不到的位置，或用末尾一句限制为夸张标题兜底，均不构成保义适配。

来源及核验细节可以按读者需要移到引用、备注或证据区，但归属、确定程度与会改变理解或执行的条件必须在实际消费处可辨。不为面向外行把未知改成确定，也不把第一人称真实性换成亲切感。

容量与材料矛盾时，先在目标载体调整结构；还需删关键论据、换主张或扩大承诺才能满足目标时，指出实际取舍与影响，回交作者主线。已有明确修订授权继续有效，不要求再过一次形式审批。

## 适配并验证

1. 按上节核对目标读者要理解、判断或执行什么。已有条件足够时自行安排入口、层级、分页与节奏，不重开总规划。归属、引语或材料支持可能受压缩影响时读[作者与来源](references/shared/author-and-source.md)。
2. 完成目标阅读关系，逐项对应原稿。保留条件、否定、责任、数字对象、时序、来源与未知；必要限制留在对应主张或动作旁。内容超容量时拆页、调整安排或在原授权内缩小范围，不缩字、隐藏正文或用多处摘要代替完整交付。
3. 目标含视觉方向或阅读界面时采用[设计提示](references/shared/artifact-prompts.md)，从真实内容与阅读任务选择，不固定模板、候选数量或外站参数。需要用户审美取舍时提供具体候选与理由；机械检查不能替代人的接受。
4. 可以由离线 HTML 满足目标时，读[呈现合同](references/shared/artifact-rendering.md)，运行[呈现脚本](scripts/render_artifact.py)，生成图卡式页面、幻灯片或阅读网站。必须打开当前 HTML 核对全部页、最密页、来源、备注和实际导航；生成与内容指纹不代替这一步。
5. 图片、可编辑 PPTX、音频或视频先按[真实载体适配](references/shared/media-adapters.md)读齐所选工具的当前合同，确认可用依赖、素材与授权，再在新位置制作并检查目标文件。HTML 预览不能证明 PNG、PPTX 或视频已经生成。目标依赖缺失时交付可用派生内容与最小依赖，标明载体未完成，继续不依赖它的工作。

适配后的中文书面或口播可运行[书面检查器](scripts/check_prose.py)或[口播检查器](scripts/check_spoken.py)，适用边界见[检查器说明](references/shared/text-checks.md)。提醒按语境复核，不自动改稿，也不作为事实或作者接受裁决。

若改变读者入口必须新增事实、改因果、换作者主张或删除核心论据，适配已不足以满足目标。保留有效派生版本，带具体问题返回作者主线或成文工作；已有该项授权时直接继续，不要求重新批准整段流程。

成熟内容需要状态图、时序图、关系图或同条件比较以帮助目标读者理解时，可采用 `507-visualize`；图表作为同版派生表达，保留原稿含义与来源，适配仍负责最终载体。简单文字或表格直接完成。

## 完成与接力

- **完成**：当前请求的受众、容量与阅读关系已经落实，关键含义、归属和来源保持；实际目标文件可打开并完成相称内容和呈现检查，降级与未覆盖明确。只请求适配内容时内容包即终点。
- **返回**：交付派生内容、当前版本与真实载体结果；父目标有已授权后续则继续。目标实物缺失保持未完成，不把准备包称成成品；发布仅在另有具体授权时进行。
- **恢复**：材料、工具、素材许可或验证不足时保留可用旧版与失败信号，交付已成立部分及阻塞动作。没有兄弟技能仍按相同责任边界直接处理，不以安装为前提。

本次出现制作比较站或关系阅读工具时，读[对象关系、比较与观察](references/shared/visual-understanding.md)并在本职责原权限与完成边界内采用。

用户点名呈现参考，或目标载体方向有会改变做法的缺口时，读[视觉方向与真实反馈](references/shared/visual-direction.md)，按需查已授权来源、优先复用已有能力并承接选定效果；已有方向与普通局部修改直接继续。

本次出现真实中断、上下文压缩或转交时核实际版本、写权、有效尝试与未完成；普通结束跳过时，读[真实中断、交接与续办](references/shared/continuation.md)并在本职责原权限与完成边界内采用。

本次出现制作可操作载体，范围止于呈现而不修改正式业务时，读[操作、状态与实际呈现](references/shared/interaction.md)并在本职责原权限与完成边界内采用。

本次出现只借呈现结构，不改成熟稿主张与事实时，读[参考视听证据与原创借鉴](references/shared/media-study.md)并在本职责原权限与完成边界内采用。

本次出现目标包含真实音频或视频，沿成熟制作工具核实物时，读[媒体版本、时间与验收](references/shared/media-production.md)并在本职责原权限与完成边界内采用。

需要实物身份时按[文件回执](references/shared/artifact-receipt.md)使用[组件](scripts/artifact_receipt.py)。文件回执不裁决渲染、语义、许可或接受。

中文密页、图表或视觉关系需要展开时，读[视觉语义与中文呈现](references/shared/target-design.md)，保护实际内容关系与当前目标文件。

明确传播目标或标题优化请求时，读[标题与正文兑现](references/shared/title-promises.md)；普通文档不因载体名称启动增长任务。
