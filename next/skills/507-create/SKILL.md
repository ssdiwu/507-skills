# 作者主线与作品责任

让受众得到当前作品承诺的理解、感受或行动，选择材料、结构与载体来兑现它。作者主张、说话位置、事实与承诺由本任务持续负责；扩展名、平台和视觉形式不决定主要身份。

## 输入、权限与直接进入

承接创作目标、受众、作者材料、指定稿件、已确认结论、排除项与交付范围。以用户修订的权威版本为基座，不因另一稿时间更新便替换。已清楚的成文、成熟稿局部修订或载体适配直接完成相应动作，跳过选题、采访、主线重建与完整技能链。

只要求讨论或建议时不写入稿件；要求创作或修改时完成范围内可通读作品及相称验证，常规措辞、结构与可逆载体选择自行处理。保存位置复用项目现有约定或用户指定位置，不另建同题竞争主稿。账号登录、消息发送、付费生成、平台发布和 Git 动作按具体授权，不包含在普通成文权限中。

作者主线、公开承诺或责任确有实质未决时，只处理会改变下一动作的缺口；已确认方向直接承接。“继续”“可以”“按这个做”能授权推进，不能单独证明作者认可此前 Agent 提出的命题或整段措辞。

## 构造与完成作品

1. 辨认作品要兑现什么、作者凭什么说、受众现在卡在哪里。真实措辞、经历、判断与明确修订是作者声音的依据；不补造亲历、态度、引语、数字或第三方反馈。
2. 判断材料支持主线哪一步。亲历、外部事实、作者判断、推断、准备案例与待核验材料分别处理；多个来源组合须有身份与关系依据。材料负载决定范围、时长或页数，不能靠重复改写填满目标。
3. 仅在真实主线竞争或材料仍不足时，读[作者与作品判断](references/authorship.md)，处理竞争解释、独立材料、作者归属与声音。充分的既有主线和材料直接采用，不为模板补问或建卡。
4. 完成可从头使用的作品，再按反馈修订；用户明确要求逐段协作时才采用。局部修订保持指定范围、原意、论据关系与有意节奏；结论强弱、因果、责任、条件或论据删减的变化在授权范围内核对，不藏进润色。
5. 核对正文的承诺、主张和当前版本，按实际载体检查可读、可听或可操作结果。内容成文、载体可用、作者接受与发布分别成立，视觉包装不替代内容缺口。

作品含已确认交互或多个相连模块时，兑现的是可连续使用的整件产物；先按[可观察验收](references/shared/validation.md)对账有效目标，不能把共同外壳里的独立演示当整合。读[操作、状态与实际呈现](references/shared/interaction.md)核动作、共同状态与返回，以及已有设计中的可访问性和偏好保障。素材缺失只阻塞依赖它的部分，不撤销与素材无关的已确认要求；局部作品保持原范围。

## 方法与载体按缺口采用

材料身份、去重与支持位置需要独立处理时可采用 `507-material`；结构、完整成文或指定稿修订用 `507-compose`；阅读容量、显隐与媒介关系变化用 `507-adapt`。事实调查或概念理解只在当前内容需要时采用，结果返回后作者主线与作品责任仍由本任务持有。相邻技能不可用时，按本合同直接完成同一工作，不等待安装或要求用户调度。

值得独立处理的材料核对、候选稿或载体工作可按需采用 `507-coordinate`；本任务继续负责作者主线、声音与整件作品，写作不以软件工单或完整协作链为前提。没有相邻技能时按同一协调边界直接工作。临时任务网页由既有过程记录经组件派生；需要网页时使用可用的任务视图组件或委托协调能力，不能直接编辑生成 HTML 补进度。当前环境无组件且制作不在本次范围时交回现有记录与明确依赖，不冒充已生成网页。

图卡、PPT、网站、配音与视频是按目标采用的载体做法和工具，不为扩展名另造主要技能。使用已有成熟能力或具体组件，交付用户真正要求的成品并核验实际呈现；只要讲稿或逐页内容时，止于内容，不自动制作其他载体。正式产品的权限、操作和恢复另由其行为依据约束。

## 完成、返回与恢复

- **完成信号**：约定作品或指定修订已完成，作者归属、材料支撑、含义与声音一致，未确认主张和责任没有冒充定案；所要求载体经过相称检查。局部请求停在指定范围，未收到作者反馈时不宣称已获接受。
- **产物**：当前权威位置的完整主稿、精确修订或显式标明状态的候选，附必要来源、含义风险与未覆盖范围；按授权包含可用载体及实际检查证据。
- **候选出口**：材料、事实或真实作者取舍补齐后返回并继续作品；仅成文请求完成即结束。载体尚未完成且原目标已授权时继续制作与验证；发布只按具体授权，不从作品接受自动推出。
- **回退条件**：关键事实、作者位置、材料关系或承诺未成立时，保留当前稿和已确认部分，指出具体缺口及它阻塞的内容，继续独立部分；材料只支持较小范围时缩小候选或补材料，不造证据、不用包装掩盖不足、不用假平衡重引已排除方向。

本次出现作品的外部事实或传播借鉴需要取证时，读[外部取证与证据交接](references/shared/external-research.md)并在本职责原权限与完成边界内采用。

本次出现作品视觉方向未定，需要真实结构粗稿和反馈时，读[视觉方向与真实反馈](references/shared/visual-direction.md)并在本职责原权限与完成边界内采用。

本次出现真实中断、上下文压缩或转交时核实际版本、写权、有效尝试与未完成；普通结束跳过时，读[真实中断、交接与续办](references/shared/continuation.md)并在本职责原权限与完成边界内采用。

本次出现尚未表达的作者亲历或判断影响当前主线时，读[显化作者一手材料](references/shared/author-interview.md)并在本职责原权限与完成边界内采用。

本次出现需要借鉴手法，保留原片取证与原创蓝图边界时，读[参考视听证据与原创借鉴](references/shared/media-study.md)并在本职责原权限与完成边界内采用。

本次出现整体视听作品需对齐内容、声音、素材和版本时，读[媒体版本、时间与验收](references/shared/media-production.md)并在本职责原权限与完成边界内采用。

实际目标为图片、可编辑幻灯片或媒体时，读[真实载体适配](references/shared/media-adapters.md)，复用当前成熟工具；需要实物身份时按[文件回执](references/shared/artifact-receipt.md)使用[组件](scripts/artifact_receipt.py)。文件回执不裁决渲染、语义、许可或接受。
