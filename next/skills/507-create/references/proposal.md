# 面向人的正式方案

目标是让特定读者能够理解、批准或执行活动、培训、合作与项目安排时使用。具体软件行为和验收规格不在此方法中。

先复用已确认读者、目标、范围、约束和成功标准。已有资料中的人数、费用、角色、频率、日期和责任不能从参考方案类推；Agent 自行安排章节和表达，用户拥有真实业务承诺与会实质改变目标、成本或风险的决定。

只要求讨论稿时在同一文档区分已确认内容、建议和待决事项，不把章节完整或状态名当成已批准的执行依据。明确缺项影响某环节时保留未知，不能为了方案看起来周全补出负责人、预算、日程或验收。

方案围绕下一次真实决定与行动组织：读者要决定什么、采取什么动作、前提是什么、谁承担责任、需要哪些资源、什么结果算完成。实际不同的出资、交付、参与和招募角色分别说明；真实相同的栏目可以合并，不用同一收益反复填表。

正式与易读并存。删掉没有事实作用的宣传词、制作过程和自我辩护，保留执行所需的约数、条件、否定、例外与边界。表格用于角色、步骤、资源或并列比较，章节数随方案规模决定，不套一套“完整”目录。

交付前从第一次阅读者视角检查歧义、错误前提与矛盾，再核对每个获授权执行环节的规则、数值、条件、责任与产出。资料足够时完成整份可通读方案，不逐章让用户承担普通写作决定。方案获批、开始执行和实际成功需要各自证据。
