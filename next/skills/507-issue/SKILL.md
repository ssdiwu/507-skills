# 可跟进工单

让一个值得持续跟进的问题有明确身份、当前状态和独立接手所需依据。复用项目现有工单平台及同一对象，正文维护当前结论，评论或既有历史位置保留证据；工单负责跟进，现行规格负责完整行为，不维护两份需求全文。

## 输入、状态与权限

承接目标仓库／平台、已有工单、用户请求、现行要求、证据及具体写入授权。只起草时交付对话草稿，不伪造编号、URL、负责人或完成状态。创建、更新、评论、分派或关闭平台对象分别服从当前授权；只读查看不变成写入，记录需求也不自动取得实施权限。

| 状态 | 能交给接手者什么 | 成立条件 |
| --- | --- | --- |
| draft（草稿） | 可复制正文、建议成熟度、可回查的现状与必要依据、缺口和下一动作 | 尚未写入平台；按拟议调查或执行状态准备可接手内容 |
| investigation（调查态） | 现象、影响、当前证据、关键未知及对应的下一证据动作、推进／升级条件 | 问题值得跟进，但原因、范围或验收尚不充分；有有效尝试时保留结果与排除依据 |
| ready（执行态） | 目标行为、范围／排除、依赖与可独立判定的验收 | 事实和用户取舍充分，无阻塞冲突，可不读原聊天领取 |

调查态不包装成实施合同。事实未知先查证，实质产品取舍才返回用户；明确需求可以直接进入 ready，不强制经过调查。发现多个可独立验证结果时才按完整用户路径拆分，避免按数据层、API、UI（界面）、测试水平切片。

## 组织可接手正文

起草和改写时直接采用以下做法，不以远程写入获授权为前提。按任务大小组织短段、条目或表格，不要求固定长模板或多轮用户确认。

1. 把已查到、会影响接手判断的现状和结论写入正文，带上可定位的版本、路径／链接或必要摘录，并说明支持范围；说明中讲过、资料中读过，不等于工单正文已经交接。纯文本需求以原要求为依据，不强造附件。
2. 区分已确认事实、候选办法和必要未知。只保留产生新信息的有效尝试：假设、动作、实际结果、据此排除或保留什么；没有有效尝试不填空模板，不把候选实现写成已定案。
3. 对会改变下一步的关键未知，写明从哪里取得什么证据、下一项具体读取／试验／决策动作，以及何种结果允许继续、改道或升级 ready。只列“还需研究隔离、质量、成本”等问题不足以接手；产品阈值未定时保留取舍，不编造数值。已有充分依据则直接给执行范围和验收，不另造调查。
4. 交付前按当前状态自检可复制正文：下一位能否找到现状依据、识别未知、开始下一动作并判断推进条件；ready 的行为、范围／排除、依赖及验收能否独立判定。缺证时保留调查态和补证动作，不以“尚未 ready”本身判失败，也不靠正文外的解释补齐交付。

## 维护同一对象

根据目标读取仓库规范、适用模板和身份／分派约定；维护已有对象时，再读平台当前对象。旧信息、新证据和用户修订逐项对账，默认同一调查单原位升级；已有重复对象先确认身份，不机械另建。新结论回正文，被取代的决定及原因在历史可追溯；Agent 的工程判断不伪装成用户决定。

依赖使用实际对象或明确未建立状态，不发明编号。已有规格只写可领取摘要并回链唯一正文；规格侧的必要来源链接在原授权范围同步，否则交回其维护者。工单不能代替实施或人的验收。

已授权对应平台动作时，读[平台写入与核验](references/platform-write.md)，准备持久可访问的证据并完成写入。写入后读回状态、正文、实际标签／负责人、依赖与证据，部分失败保留真实对象和待补项，不重复创建或宣称全部完成；只起草止于上述正文交付。

## 按需依据

| 条件 | 读取与用途 |
| --- | --- |
| 证据版本、故障事实或来源归属不清 | [事实与来源](references/shared/evidence.md)：核实支撑范围 |
| 用户修订、状态升级或决定取代 | [权威与返回](references/shared/authority-and-return.md)：保全条件，正文只保留当前结论 |
| 是否可升级 ready 或验收是否成立 | [可观察验收](references/shared/validation.md)：拒绝仅有清单或自报的放行 |
| 写入许可、责任或产品取舍实质不明 | [决定归属](references/shared/decision-ownership.md)：区分授权与可逆编辑选择 |

## 完成与返回

草稿已可接手且状态明确，或授权平台动作已实际完成并读回核验；交付对象链接／正文、证据入口、未完成项与依赖。只要求记录时结束；父任务已授权实施且 ready 时带当前合同返回实施，不要求用户重新给同一授权。

关键证据或取舍失效时保持／退回 investigation，说明阻塞和下一证据动作。平台状态未知时先读回，不盲目重试非幂等写入，不为失败改权限或伪造完成。

本次出现真实中断、上下文压缩或转交时核实际版本、写权、有效尝试与未完成；普通结束跳过时，读[真实中断、交接与续办](references/shared/continuation.md)并在本职责原权限与完成边界内采用。
