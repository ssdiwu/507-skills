# 项目依据与导航维护

作为主要技能，承接项目工作依据的建立、迁移、维护或只读核对，负责本次文档结果与必要引用的一致性。用户主要通过本入口表达这类目标，Agent 也可按需采用；沿用指定项目、有效决定和已有授权。让维护者找到现行要求、共同规则、真实入口与验证依据，不接管产品开发、故障修复或架构改造的全部责任。

## 与规格、工单的职责关系

| 能力 | 负责什么 | 如何承接已有内容 |
| --- | --- | --- |
| setup：主要技能 | 项目工作依据与阅读导航；按本次范围建立、归位或维护 | 规格与工单各有原正文，导航引用它们，不另抄一套需求或状态 |
| spec：次要技能 | 已确认功能的唯一现行行为与验收规格 | 需要编写或修改行为正文时按原授权采用507-spec；已有充分规格直接沿用 |
| issue：次要技能 | 软件工单的身份、调查／执行状态、依赖和证据 | 需要持续跟进软件问题时按原授权采用507-issue；工单摘要回链规格，不代替规格 |

三者按本次缺口采用，不串成初始化后的固定步骤。只要求整理项目依据时以该结果结束；原目标已授权实施且依据充分时返回原任务继续，不要求补一轮规格或工单。

## 输入、权限与停止位置

承接指定项目或文件、有效版本、用户修订、已确认决定与当前授权。先核对实际入口、工作树和已有改动，明确唯一写入者、允许正文与必要消费者。只读请求只交证据、缺口和建议。

| 请求 | 当前可处理范围 |
| --- | --- |
| README、目录说明、spec/doc 导航或局部地图维护 | 仅指定地图和必要上下级引用；不改规则、设计、词义、进度、规格或业务实现正文 |
| 项目初始化、依据建立或已授权规范迁移 | 规则、已确认词义／共用设计的整理归位、相关当前快照及直接导航；具体行为正文沿现行规格职责维护，不改产品意图或源码 |
| 按标准只读巡检 | 读取范围内依据、实际入口与验证信息；不补文件、测试或工具，不将巡检完成当迁移完成 |
| 明确指定的全局 AGENTS.md 校准 | 仅指定文件及必要来源；不猜宿主路径，不顺带迁移当前项目 |

局部导航任务只读[项目导航](references/project-navigation.md)，核当前入口，完成指定地图及必要引用，检查链接和阅读路径后即可交付；跳过完整依据巡检与迁移，不因缺少文件而补建规则、规格、进度或工单。

建立、巡检或迁移工作依据时读[项目依据](references/project-foundation.md)，按实际风险选择完整或精简职责，不创建没有内容与消费者的文件。全局文件只采用其中全局规则与规则维护条目，跳过项目步骤。

## 建立或切换依据

以下用于已请求的依据建立、巡检或迁移；只读时仅核对并报告，局部导航不展开本节的完整工作。

分别核对应该怎样、现在怎样实现、实际验证到哪里。现有缺陷不删减已确认要求；旧计划、未勾选项和历史候选不自动成为现行目标。规则变化说明具体防错对象、适用条件与依据，已有机制能够承接时才退役；篇幅、固定清空周期和模型升级不能单独证明安全。

迁移先按内容建立来源、唯一目标与受影响消费者映射，保全有效条件、排除项及未完成。隔离候选通过含义、来源、覆盖与链接核对后，在同一受控变更切换正文和引用；清理无消费者的重复正文，历史保留后继入口。必要迁移指引记录真实消费者和退出条件，不继续维护第二套现行正文。受保护原件、生成文件、嵌套项目、冻结样本和其它工作树沿其所有权处理。

当前维护正文仍点名旧技能时，读[旧引用与当前职责](references/shared/skill-entry-resolution.md)，查询包内声明后在获授权范围校准引用，保留原动作许可和停止位置。未授权的全局规则、自动化及其它项目只交差距；历史原件不因旧名而改写，查询命中不表示宿主已安装或迁移已完成。

PROGRESS 只承载确有接续用途的当前阶段、必要完成证据、未完成／依赖与下一动作。阶段切换先保全历史和未完成，再更新当前快照；已有细任务状态回链原工单。一次局部导航维护不能新建进度系统。

授权充分时连续完成正文与直接引用，不为本任务内部动作重复索取同一许可。必要工程保障未建立或未运行时，给具体建设动作和受阻路径，由工程实施承接；规范文字不冒充工具保障。

## 验证、完成与返回

检查本次范围的含义与来源保全、链接／锚点、实际阅读路径及变更。局部导航只核受影响的阅读路径；建立、巡检或迁移依据时，从现行要求走到共用规则、实现入口与验证依据。新项目没有实现时明确缺口，不造运行能力。巡检、文档迁移、工程可用、业务接受和发布分别报告。

完成时，本次范围的当前正文与入口唯一，授权旧维护路径已退出，未同步消费者、未完成与依赖可查。交付相应文件或只读结论、来源与验证、下一步开工条件；不能用新目录存在或地图准确称全项目迁移完成。

规则、权限或正式需求变化由另一执行者独立 review。只要求维护时结束；原目标仍有授权工作则携当前依据返回继续，提交和发布按具体授权另立结果。权威冲突、所有权不清或候选未通过时保全可用基线，只暂停依赖部分。

本次出现真实中断、上下文压缩或转交时核实际版本、写权、有效尝试与未完成；普通结束跳过时，读[真实中断、交接与续办](references/shared/continuation.md)并在本职责原权限与完成边界内采用。

持续依据维护按[工作记录](references/shared/work-records.md)主动保存当前范围、迁移依据与未完成消费者；必要记录没有归处时，只在本任务可写范围补最小位置与入口，不自动创建整套规则、规格或进度系统。局部导航和只读限制仍优先，项目特有约束留在项目。
