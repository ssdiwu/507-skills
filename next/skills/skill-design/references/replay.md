# 验证与演进

用于触发、权限、产物、接力或资源变化。只改错字时做相称自查，不机械生成评测项目。

先检查可独立读取：元数据有效、名字一致、相对引用存在、所有必要资源为包内普通文件或明确外部工具依赖。把单包复制到没有作者仓库的位置再检查，才能证明该范围的资源闭包。

行为改变选择有区分力的真实请求：正例、同词不同目标的反例、只读/受限授权、已有充分确认、父任务尚未完成的续办。执行者只拿任务、候选和最小材料；期待结果与已知失败由检查者另存，避免把答案教给执行者。

记录选择、实际读取、动作、产物和停止位置；声明哪些是静态推演、隔离执行、真实工具或人的验收。没有同条件实测不声称更省令牌、更快或更自主。

发现失败时保留反例及旧基线，只修相关条件，再检查受影响路径。完成后由独立审读者按目标、权限与证据收口；无需因为共享方法存在而再次跑全库或向用户索取已给出的授权。

来源融合保留版本、许可和适用范围。旧技能身份可被取代，安全、作者意图、数据保护和有效授权需在新组合中有明确承接；不以删规则后等待事故来证明退役安全。
