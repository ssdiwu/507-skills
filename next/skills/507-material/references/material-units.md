# 材料单元与交接

需要从混合文本、研究交接或作者叙述中提取可消费材料时采用。先围绕当前作品需要整理，不做无边界摘抄。

每个单元应脱离原材料仍可理解，并能回查原来源。可以是一项经验、一段过程、一个问题、一条判断、一份事实证据或反例；不按句子数量、表格行数或改写次数计数。

```md
材料：<清楚说明对象、动作或判断>
身份：<事实 / 来源自述 / 亲历 / 作者判断 / 假设 / 问题 / 未知>
来源：<文件、页段或对话锚点及当前版本；说话者按需>
支持：<能支持哪个具体判断、过程或表达位置>
边界：<必要条件、反例、不能推出什么、仍需核验什么>
```

字段随材料取用，普通单元可写成一行；重要条件不能因简写丢失。同义复述合并时保留确实不同的条件，不把共同标题当成合并依据。来源出现冲突时列明相同与不同的对象、版本、场景和证据，不为“整理得顺”调和成结论。

需要持久化时先核对既有材料、作品与资料库规则，再决定新建、补充或跳过。关系应能用具体内容解释，例如支持哪项判断、反驳哪个条件、延伸什么机制；同标签和相似措辞不足以建关系。用户只要求给当前作品备料时，交付材料清单即可，不附加长期知识库写入。

交接说明已整理的材料、合并了哪些重复、哪些位置可使用、哪些位置仍缺依据，以及它阻塞哪个动作。材料不足也是有效结果；不能为了凑材料数量制造判断、案例或反证。
