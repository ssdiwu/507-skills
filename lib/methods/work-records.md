# 持续工作的记录与读回

持续定义、设计、调查、实施或跨会话工作产生会影响后续动作的实质信息时采用。必要记录属于当前任务责任，无需用户另说“记下来”；简单答疑、一次性微小修改不强制建立过程文件；但已有计划或记录明确要求结果回写时，应在该处或其指定位置保存实际结果与必要验证状态并读回，不因任务小或单阶段而忽略，也不用聊天汇报代替。明确只读、不写任何文件或临时讨论时遵守限制；受审对象只读时仅写允许的独立证据位置。

## 找到实际归处

先读现有入口与有关正文，沿项目规定的位置维护；已有规格、方案、事项或稿件能够承载就原位更新。没有合理归处时，在已确定的本地工作位置建立最小记录并接入阅读入口，不预设固定文件套装。位置或所有权存在实质歧义才补问。保存本地依据也限于本次允许位置，不授权任意临时目录、复制或清理；共享平台写入、发送、提交、发布或个人长期记忆更新仍依各自许可。

按职责保留足够接手的内容：有效目标与排除项、决定及原因、当前方案与产物版本、关键证据、产生新信息的尝试与否定结果、未决依赖和下一动作。已有原件回链，不复制完整聊天、每条工具调用或敏感数据。记录可以比汇报完整；给用户的汇报提炼当前进度、差距、阻塞及必要决定，不将记录压成固定四栏。

## 实质进展时更新

用户要求/决定、授权内 Agent 选择、候选建议、实际观察、推断和未验证内容须可辨。记录不等于采纳建议。新决定成立时更新受影响正文、操作关系及验证条件；旧理由与失败证据沿现有历史位置保留，不并存相反现行结论。几轮讨论形成一项结论可以合并更新，不每句话写文件，也不等压缩才抢救。

阶段任务的要求与状态分开维护：规格不变时保留要求正文，但仍把本阶段完成、实际复验、未覆盖和下一步写入现有计划/过程记录。不能用“恢复既定行为、无需改规格”代替这项记录。当前快照服务下一动作，历史过程服务追溯，正式产物承担其原职责；同一结论只有一个现行正文。每个执行者维护自己的产物与证据，指定整合者维护共享记录，同一工作树只有一个写入者；没有写权时交回可整合差异，不能抢写。投影视图由源记录生成，不成为第二总账。

## 接续和结果

新执行者先按当前请求读取入口、有关正文、版本与证据，恢复有效目标、排除、写权、已有结果和下一动作，再继续未完成部分。中断或压缩前只校核尚未保存的必要状态，详细接续边界由 continuation 方法承接；不重新抄一套长期记录。

修改后读回实际记录及相连正文，核含义、内容身份、版本和未决一致。记录完成不是业务完成；内部结果回到原目标，达到约定范围即止。业务写入、独立验收、人的接受和发布分别保留证据。

来源：由 507-work 的 process 方法提炼通用记录与读回，事项身份和平台状态继续留在 work 的专用参考。
