# 作品版本、语义保护与载体交付

需要安排受众正文与审阅依据、承接用户改稿、同步多个派生载体或替换可用旧版时，按缺口采用对应章节。它维护内容与呈现之间的合同，作者主张和发布授权沿原任务处理。

## 从有效内容派生

先定位指定稿件、用户手改与当前有效版本；更新时间不能自行取代指定版本。成熟内容直接使用，不为了适配新建创意卡、重开作者采访或强制重新规划。主稿与派生稿各有用途；不要把同题旧稿、平台稿与主稿都当作当前内容权威。

对修订保护数量与修饰对象、单位、权限、否定、例外、时限、责任主体、引语、归属、因果、先后、完成状态和确定程度。标题、引语、术语与代码标识保留作者已经采用的表层形式。表达优化不自动允许改结论、删论据、补逻辑或增加公开承诺；已有授权覆盖含义改变时据实修改并说明影响，否则保留原意，把候选与含义风险另列。

改变主张或核心因果时，重新检查真正依赖它的段落、标题、备注与已请求载体。用户指定叙述顺序或收尾时，按实际讲述或阅读顺序通读，确认新增总结或行动提示仍保留指定的收尾。局部改字只检查局部及必要上下文。多个输出承载同一修改时，以当前唯一内容版本同步本次相关产物，不强制生成未请求的载体。

用户以一处问题要求检查类似内容时，先辨认被纠正的是事实判断、受众口径还是呈现关系，再核本次交付中依赖同一判断的页面及相关载体，逐处决定保留、改写或删除；不能只替换示例句，也不能把不适用的内容一律删掉。明确只改一处时仍止于该范围。

## 根据受众和容量安排内容

先明确读者需要理解、比较、决定或完成什么，再为每一段或页选择能推进该目标的内容。在确定正文前，按信息的实际作用放置：

| 信息作用 | 放置办法 |
| --- | --- |
| 支撑主张、解释状态或帮助操作 | 直接写出判断、必要依据和对读者的影响，同一信息按需要集中讲清 |
| 改变读者理解、选择或操作的条件与未知 | 紧贴相应主张或放在操作之前；可查且影响实用性时先查清 |
| 用于核查来源、备讲或记录制作过程 | 按用途放引用、讲者备注或内部审阅说明；完整验收报告按约定保留通过、失败与未验 |
| 已有同义内容或无读者用途的提醒 | 合并或删去，复核删改后读者仍能理解和行动 |

例如队列等待页可以说明「这里显示全团队待处理的数量。排队较多时，可以稍后提交。」若批次号用于之后查找，则说明从哪里找回。路演采用几何估算时，标题或图注写清估算对象和口径，详细计算留给审阅。方案可以明确推荐某个试点，实施所需且尚未取得的资料仍在对应建议旁作为前提。

页面容量不足时先重排内容或分页，按原授权处理范围取舍，保持正文可读且关键依据可见。核对标题和正文对同一事实的归属、范围与确定程度，保留作者声音。确认正文、讲者备注、来源和内部审阅材料各自对其读者可用。

文章转图卡默认保留整篇及顺序；只有明确要求提炼时才形成摘要，并说明重要未入选内容的去向。讲述页按认知台阶组织，备注与口播不自动进入观众页面。网站按寻找、阅读、比较或下一动作组织；浏览节点不表示源流程已经执行。

## 对当前目标载体验证

在新位置制作候选，验证通过后才按项目既有机制替换可用结果。失败保留旧版；脚本运行成功不构成语义、真实呈现、作者接受或发布的证明。

核对当前内容与输出的对应关系：必要内容和来源有没有遗漏，顺序与条件有没有变，实际输出是否可打开，可见文字是否可读，长内容、窄屏、键盘与必要降级是否仍能完成阅读。图片检查真实尺寸与画面；PPTX 检查编辑对象、备注和逐页渲染；音视频以实际音频、字幕、时间线与成片为准。没有对应工具或实物，只交付内容包和明确依赖，不能声称目标载体完成。

多页作品还需并排核对同类页面的标题、副标题、标识位置、字体搭配及信息层级；有意变化由页面任务解释，不能只用逐页无溢出判整套一致。按内容关系决定合页或拆页，避免把原本连贯的一组信息拆成多张空页。截图大小须让目标区域可辨且不挤掉必要解释；画面、背景与该页主张的对象和来源相符，示意图不冒充实际产品。已请求的导出版本核实际字体和版面，源文件正常不证明导出正常；已要求保留的动图或视频还须核媒体保全及可用性，静态预览不能证明播放通过。

返回包括实际文件或正文、绑定内容版本、检查证据、降级与未覆盖部分。成文、HTML 生成、图像导出、可编辑 PPTX、视频渲染、人工接受和平台发布分别成立。只有内容本身是终点时可在内容完成后结束；父目标要求呈现时继续已授权工作，遇真实依赖缺失报告它阻塞哪个结果。

当前消费者：create 在安排正文与审阅依据、已有稿修订、完整内容交付、作品出口及多载体接力同步时采用；adapt 在受众、容量、内容版本和呈现实物核验时采用。来源为旧 forge/rednote/ppt 的语义保真、内容状态与安全替换合同；不继承旧工具的固定页数、字体、风格或环境依赖。

独立验收者 C 核对实际主稿、派生稿、用户修订和交付版本，按内容与载体完成相称检查；制作过程自报和文件存在不代替核实。C 不修改受审作品，作者审美与最终接受另列。
