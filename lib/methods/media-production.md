# 声音与视频的真实版本、时间与交付

当前请求包含真实配音、音频或视频成品时采用，给宿主制作工具提供内容、时间、素材和验收合同。内容已成熟直接制作；只要旁白、分镜或逐页内容时止于内容，不顺带生成媒体。方法不规定制作引擎，不重造配音/剪辑工具。

## 复用内容与素材状态

恢复已有项目时先读取有效入口、内容、分镜、风格、素材清单、最近预览和失败，沿原文件角色继续。制作最低依据包括目标及受众、核心主张、当前内容版本、交付规格、素材用途/来源/许可、事实及隐私边界、声音来源和主时间基准。缺少会改变目标、成本或风险的用户决定时回交具体取舍；可查信息与常规参数由 Agent 核对。

每项媒体实际读取元数据并抽样检查，登记稳定 ID、相对路径、角色、节拍、尺寸/时长、来源、许可、必要 credit、隐私处理与 planned/resolved/rejected/replaced 状态。付费和外部上传依原授权；不要因生成工具可用自动获得素材、声音或公开用途的许可。

## 声音身份与真实时间

普通旁白可用宿主现有 TTS；用户指定本人或特定授权声音时精确核验身份、当前用途授权和既有档案，人未确认的声音身份不能由列表顺序猜测。不得因软件/模型许可证推定声音已获权。样本、档案、生成音频与本地清单不进入公开技能仓库。需要新声音采集时停在原工具授权边界，不扩成默认克隆流程。

先读取工具实时能力与兼容组合，必要时短样本试听后锁定本批参数；技术结构验证不能证明音质、语气或声音相似度。生成异步任务须等成功终态再下载，失败、取消或超时保留错误。使用最终清理、变速或混音后的真实音频测时；文字预算、原始音频时长与最终帧数分别记录。

一个项目选择一个主时间基准：最终声音、录像入出点、已验收音乐拍点或无外部时钟的人工时间线。其他画面、字幕、动效与音效向它对齐。逐段音频用稳定 ID、正文/音频哈希和实测起止交接；仅段落 timing 不冒充逐字字幕。主时间、旁白或声音变化使受影响字幕、分镜、时间线、预览和确认失效。

## 预览、确认与母版

使用当前制作工具提供实际可播放、可定位时间码或帧的预览，绑定内容、素材、声音与项目版本。既有项目或本次任务约定用户审片时，沿该门提交当前版；反馈引起可见/可听变化后重新预览，旧确认不能传给新版本。对仅要求直接生成完整视频的清楚请求，承接现有生成/导出授权与当前宿主合同，不要求用户念固定的渲染口令。

先做结构、时间线与运行检查，再核对关键帧和整片节奏/声音。按改动最小重跑：视觉改动不重做无影响声音，旁白变化须重建对应时间链。制作与正式渲染用同一输入版本，不覆盖可恢复旧母版。

成品核验实际可播放、时长、画幅、分辨率、帧率、编码/音轨、字幕可读性、安全区、音画漂移、黑帧、空白和素材缺失；抽查开头、场景边界、高潮、结尾与高风险画面，自动检查不能代替观看或聆听。交付实际文件、指纹、规格、时间基准、来源/授权摘要、检查与未覆盖、可恢复源项目。文件生成、技术通过、人工接受和发布各自成立；发布与账号操作依原授权另行执行。

## 仅真实产品视频采用的证据分支

# 产品宣传片中的真实功能证据

视频以真实网站、桌面端或移动端产品状态为主要证据时采用，在已有视频简报、分镜、风格、素材与审查记录中补充条件，不建立第二总控或固定制作模式。

只读理解指定产品的入口、版本、主要页面/窗口、运行方式与品牌依据。把核心主张拆成必须展示功能，每项明确观众要理解什么、页面状态和允许作出的事实判断。公开、虚构与脱敏数据分别标记；敏感账号、客户、路径和会话信息在采集前处理，空骨架与未核验活数据不能当已展示功能证据。

从当前产品提取字体、色彩、层级、间距、材质、轮廓与已有动效，沿项目风格约束使用。方向不明时用少量安全预检素材做真实画幅静态风格帧，检查构图和可读性；已有品牌/确认方向直接复用。宣传表达可以调整层次，真实产品界面与未实现功能不能凭效果图暗示。

先建立功能/主张到镜头任务的一一映射，记录页面证据、首选/备选运动结构、可读性和实现风险、素材缺口。镜头语法只描述进入、动作、停留、离开及必要时值，不承担事实来源；借抽象手法仍保留原创边界。完整分镜据此安排叙事顺序、时长、字幕、声音与能量，不能以运动词汇替代分镜。

分镜与产品证据一致后才最终采集。记录产品版本、窗口/页面状态、主题/语言、视口、像素密度与隐私处理，等字体、图像和数据稳定。只采实际需要对象；元素运动需要时保留同坐标系整页、切片和位置，普通正视演示不强制三件套。预检图不能自动升为正式素材；页面、产品、令牌或分镜变动后最小重采。

音乐真正主导节拍时先验收节拍和段落、镜头边界锚定其依据，保留源拍点与最终输出偏移；只作衬底时不重排已经成立的声音/画面主时间。音效使用相对动作锚点，最终输出检查命中、遮盖、削波、长尾与漂移。

交付前由未参与本轮制作判断的执行者只读核对当前预览、逐镜头关键帧、功能映射、分镜、风格、素材、事实与隐私边界，按帧号/时间码报告真实状态、必须展示是否齐全、证据/品牌/声音是否一致与无法核验项。没有可用的独立上下文执行者、尚未完成当前版终检或仍有阻塞发现时，保留预览与未验证／返修状态，停在正式母版渲染前；不冒称独立审查。修复观众所见所听问题后更新对应链路并重审，最终母版按同集合核对编码、字体、字幕与隐私。
