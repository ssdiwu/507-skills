# 独立阅读页的内容与验证

成文、适配或图解的交付物是供人打开阅读的网页时采用。依据当前稿件、读者任务和具体参考决定页面呈现。

1. **先明确读者来做什么。** 从真实内容找出读者要查的答案、要作的决定或要完成的动作。开头让读者认出材料的用途。已经说清的背景只出现一次。
2. **按查找和行动组织内容。** 让读者常查的信息容易定位。例如，日程索引可以同时写活动和时间，正文把开工条件放在对应动作旁。章节较多、读者需要来回查找时提供能直接到达目标的导航。
3. **用参考指导这一件作品。** 核对用户欣赏的层次、比例、留白或阅读顺序，用实际标题、数字和材料决定如何实现。比较数据时交代尺度、单位和未知项，有依据需要回查时提供来源入口。按内容选择具体字形、版面与交互。
4. **交付能实际打开的页面。** 新建页面可从空白 HTML 和 CSS 开始，交互随读者动作而定。修改已有页面沿项目入口和既有组件工作。要求离线时检查全部必要资源在离线环境中可用。
5. **从读者的位置验收。** 在桌面和窄屏打开成品，实际查找关键答案，使用键盘完成导航和必要操作。逐项核对原稿中的数量、时限、受众、条件、例外和来源。修订后从同一位置复验。
