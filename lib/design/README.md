# UI／UX共有设计资料

这里保存按使用问题选择的设计模式、原始来源与提示模板；不是Skill，不负责总路由。模式/原5提示的实际消费者仍是本地技能对照参考站；[载体提示](artifact-prompts.md)已由compose/adapt按条件携带，具体HTML执行器见[共有组件](../components/README.md)。未来design、interaction、visualize的完整能力仍为候选。

- [模式资料](patterns.json)：16条模式的目的、条件、状态、语义、失败/输入/降级、反例、角色和组件归属。
- [提示模板](prompts.md)：交互合同、阅读比较、动效连续性、预览采用和目标路径核验。
- [来源与观察范围](references.md)：原站类别、本轮可见内容和未覆盖；私人笔记只保留私有证据。

共有模式以patterns.json唯一维护，网站从该文件生成展示。方法持有语义判断，组件只执行已成立动作；图片/页面/使用流程/交互模式/控件/动画机制是不同检索维度。看见Preview或Code入口不等于当前项目采用、运行或许可核对完成。

真实键盘/触摸、失败、中断、减少动效与目标设备在实际消费者环境验证。优先复用既有能力，参数随内容和项目方向确定，不固化外站例图数值。当前完整清单见[next](../../next/README.md)和[共有资源](../catalog.json)：按需提示进入登记消费者，不代表整套模式或所有载体已经执行，也不注册宿主。
