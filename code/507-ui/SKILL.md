# 产品界面交付（ui）

把已确认需求和视觉方向落实为完整、连贯、可用的产品界面。设计判断、范围内的实现和实际操作验证构成同一交付；请求只到建议或样稿时，就在该范围完成。

## 承接范围与依据

先核对任务对象、作用路径、允许修改的位置和当前基座。读取项目入口、相关规格与 DESIGN、已有组件及调用者；项目已有需求、用户改稿和已确认方向足够时直接续做，不因缺少特定文件名、篇幅、访谈记录或设计技能历史而重开确认。

沿项目现有组件、样式与业务通路落地。共用视觉目标进入项目的 DESIGN，具体动作、权限、状态和验收进入规格；实现与运行记录决定当前事实。一个局部任务不自动变成全产品规范迁移或视觉重做。

| 当前请求或缺口 | 处理 |
| --- | --- |
| 已有明确需求和视觉方向，要求实现或打磨 | 直接完成指定界面与验证 |
| 只讨论、只评估或只做样稿 | 给出相应结论或隔离样稿，不修改正式产品 |
| 视觉方向仍未定，影响整体构图或语汇 | 用可比较的真实候选收敛，可采用 taste 的等价方法；方向成立后返回交付 |
| 产品意图、权限或高代价取舍缺失 | 查清可查事实，仅将真正属于用户的取舍交还 |
| 只要求独立审查 | 进入只读 review 或项目等价流程，不取得修复权限 |

需要视觉探索时选择能回答当前未知的载体；不把图片样稿、固定候选数量或多轮批准作为所有 UI 任务的前置门槛。参考图表达构图和视觉意图，不替代真实文案、可访问语义或状态事实。

## 连起操作、状态和反馈

从用户实际要完成的动作开始，追踪输入或草稿、激活、处理中、确认结果以及失败或未知时的恢复。对有状态控件、标签页、异步请求、搜索、日期、表单、分享或撤销行为，按需读取[交互质量方法](references/interaction.md)，把关键规则连到实际调用者和检查。

区分可以并存的维度：输入内容、焦点、校验、可用性、选择和请求进度不必挤进一个互斥状态枚举。状态由已有业务或运行事实派生；不要为展示另建执行队列或第二份正式状态源。允许的本地草稿与正式结果分别维护。

按下可以即时响应，成功、批准、暂停或完成则需要对应正式回执。已保存、已接收、待审批、运行中和结果未知分别表达。限制同次重复提交时，保留业务仍允许的输入、取消、暂停或其他操作；不为了动画锁住整页。

结果未知时回查原操作，依据既有接口的身份与幂等约定恢复，避免把同一意图另投为新请求。失败后保留仍有效的输入与操作上下文；重要错误可继续读到并处理，不能只藏在短时提示中。

## 完成视觉与实现

在现有视觉体系内，用清楚的层级、布局、密度、标签与反馈帮助用户找到动作和结果。同类组件共用语义样式值；核对真实长短内容、各语言、浅深主题和合成背景中的可读性。占位文案不承担唯一字段名称，颜色不承担唯一状态说明。

容器、可中断过渡、直接操控或半透明材质涉及具体判断时，读取[容器与连续反馈](references/containers-and-motion.md)。平台知识按场景使用，不把 Apple 风格、弹簧、玻璃或装饰动效强加给所有产品。尺寸、时长、字重和配色比例由平台要求、项目设计与实际效果确定，作者示例不成为通用阈值。

涉及 Apple 原生交互、连续手势、速度交接、弹簧参数或系统排版时，按需读取[Apple 交互细节](references/apple-interaction.md)，再核对目标平台与已有实现。不要求另行安装或调用 apple-design。

优先复用已有组件、图标、原生语义和依赖。能复用的错误恢复、焦点和状态逻辑在共同责任处维护；独立的变化原因仍保持清楚。新增工具或动画库须有当前需求收益，避免仅为了重现参考效果更换技术栈。

## 验证实际使用

复用仍对应当前版本、输入与环境的有效证据，补足本次变化影响的路径。完成项目要求的检查；测试缺口按需要补齐，不因改了 UI 就重跑无关媒体或整个产品的所有场景。

在实际目标运行环境渲染并操作本次切片，检查关键动作是否兑现，状态与正式结果是否一致。涉及网页时观察浏览器画面及交互；原生应用使用其实际预览、模拟器或设备能力。仅看源码、DOM、构建成功或静态截图不能证明完整操作已通过。

按变化选择有区分力的覆盖：键盘激活与焦点归还、触控命中、目标视口、长文本或文字缩放、校验失败、请求失败、快速切换、关闭重开、减少动态效果等。只报告实际覆盖，不机械对每个小改套全量清单。

发现材料问题时记录并修正授权范围内的原因，再复验受影响路径；没有新问题就停止重复。工具或环境无法支持目标检查时保留可复现材料，说明缺少哪条证据；隔离模拟只能证明对应前端条件，不冒充后端持久化、真实审批、执行器或用户接受。

实现者自查之后，行为、权限、数据或公开契约的变化按项目要求交独立只读审查；本技能的自查不替代独立结论。主观视觉接受、自动检查、独立审查和外部交付各自成立。

## 完成与接力

- **完成信号**：请求范围内的界面或结论已交付；关键操作、状态、失败恢复与呈现有相称证据，未验证部分具体可查。
- **产物**：范围内的实现或隔离样稿、直接关联的规格／设计修订，以及版本、运行环境、动作、结果与限制的验证记录；只读请求产出建议和依据。
- **候选出口**：设计取舍、规格、故障、测试或独立审查按实际缺口进入相应动作；目标已达到可直接结束。提交、推送、发布和安装启用仅在各自授权内进行。
- **回退条件**：基座不明、关键取舍缺失或验证失败时保留已可用版本与失败信号，只暂停依赖该缺口的部分，不宣称候选已可交付。
