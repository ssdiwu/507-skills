# 小红书平台稿合同

`content.md` 是小红书实际可见文案与 Markdown 语义的唯一当前来源。`raw.md` 是长文主稿，不由网页自动回写；旧 `copy-spec.md` 表格式分页不再作为逐字文案或物理页的当前依据。

## Article

- 来源主稿、平台稿与编辑说明分层；正文、标题、列表、代码、表格、流程图、图片与图注全部进入图文。
- 顺序沿用主稿论证链；允许为图片阅读调整表述、符号和主动换行，不允许概括、删减、重排或补写逐页过渡。
- 第一个 H1 用于独立封面，其余标题保留在正文位置，可出现在页面中部。
- 普通 `---` 是水平线；强制分页只使用 `<!-- rednote:page-break -->`。
- Markdown 链接保持标准写法，runtime 在最终可见文字中追加完整 URL；不能为视觉简洁删去链接地址。
- 单篇容量不足时拆连续系列并说明覆盖范围，不缩到不可读。

## Summary

摘要模式另行记录中心判断、入选观点、来源与未入选重要内容去向。封面 H1 后以 `<!-- rednote:page-break -->` 分隔观点段，每段必须且只能有一个标题并完整落在一页。`content.md` 保存最终可见平台稿；来源关系与排除项进入 visual-plan 或上游内容交接，不手写物理页 JSON。

## 验收

- `content.md` 的可见语义经 runtime 编译后全部进入 `paged-content.json`，强制分页注释和 frontmatter 除外。
- 非重复 fragment 的来源范围无静默缺口；重复表头和 page chrome 不重复计算正文覆盖。
- HTML、静态图片和 PDF 不得在导出阶段改写文字。
- 物理页数只以当前 `paged-content.json`、manifest、实际图片和联系表一致的状态为准。
