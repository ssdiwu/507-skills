# 小红书图文 Copy Spec

`copy-spec.md` 是成品模式、内容边界和逐字文案的唯一真值。渲染阶段只排版，不擅自改写文案。

## 模式选择

- 用户只说“小红书图文 / 图卡 / 编辑小红书”时，使用**文章模式**。
- 用户明确说“视觉摘要 / 一页一个观点 / 提炼 / 精华版”时，使用**摘要模式**。
- 同时要求两种成品时分别建规格和输出目录，不让其中一个冒充另一个。

## 文章模式合同模板

```markdown
# Copy Spec

## 载体合同

- 来源主稿：`../raw.md`
- 成品模式：连续文章图文
- 完整性要求：标题、小节、正文、列表、图片与图注全部进入图卡
- 编辑权限：只允许连续排版、切页、原有标题层级和不改变文字的强调
- 顺序要求：严格沿用主稿论证顺序
- 页数边界：先打平旧分页并经真实浏览器布局得到实际页数；超出平台单篇上限时拆连续系列

## 媒体去向

- 图片 1：原文位置 / 显示方式 / 可读性要求
- 截图 1：原文位置 / 是否必须完整包含

## 连续文章流与切页

| 页码 | 原文范围 | 原文结构与证据 |
| --- | --- | --- |
| 1 | 标题 | 独立封面 |
| 2 | 第 1–4 段 | 正文；无新增标题 |
| 3 | 第 5–8 段、图 1 | 原小节标题位于页中；图 1 近全宽 |

## 验收

- 原文非空结构行覆盖 N/N
- `excludedContent` 为空
- 原文顺序一致，无改写、概括、删减或为了页面闭合补写内容
- 图片与图注均在原位置附近显示
- 正文没有自动页眉、页码、逐页观点标题、重复头像或装饰卡片
- 规格、清单、图片文件与联系表页数一致，目录里没有旧页残留
```

### 文章模式纪律

1. 除 frontmatter 与 Markdown 控制符外，主稿可见内容全部进入图卡；帖子正文不能替图卡补漏。
2. 先打平旧 `pages` 分组和小节分页边界，把原文恢复成一条连续文章流，再以真实浏览器中的可用画布高度切页；旧页数、字符数估算和旧页面占用率都不是分页输入。物理页面不承担观点选择或语义闭合，可以在段落、句子或转折中间续页。
3. 正文页只有 `sourceMap` 负责溯源，不写逐页 `point`、`layout`、自动标题或总结；原文小节标题作为内容块，可以出现在页面中段。
4. 图片与图注按原文顺序进入；多状态截图若在原文中是一个证据单元，继续作为一个近全宽证据单元，不缩成卡片内的小图。
5. 封面负责标题和作者识别；正文不重复页眉、页码、分类标签、头像、金句框或封面装饰。
6. 不靠不可读小字、过淡文字或视觉拥挤强塞全文；容量不足时拆连续系列。相邻页仍有大面积可用空间时继续跨旧边界重排；只有不可拆图片、截图、列表或标题防孤行确实阻断内容流时，才接受明显留白。
7. 页数只有在 `rednote-project.json`、`render-manifest.json`、实际 JPG 文件和联系表完全一致，且旧页已清除后才成立；临时测算、候选分页或只改文案表都不能称为“已经改成 N 页”。
8. 交付前做机器可复查的逐段覆盖校验，并打开联系表与最密页、图片页、跨页处和结尾页人工检查。页尾最后一个内容块的外边距由画布底部留白接管，不重复计入溢出。

## 摘要模式合同模板

```markdown
# Copy Spec

## 来源与中心判断

- 来源主稿：`../raw.md`
- 成品模式：视觉摘要
- 中心判断：一句话写清整组图卡最终要成立什么
- 读者承诺：读完这组图卡会理解什么

## 入选观点

### P1｜观点短名
- 来源：主稿第 X–Y 段 / 图片 N
- 关键证据：支持该观点的事实、截图、数据或例子
- 逐字文案：本页唯一主张与必要说明
- 页面任务：封面 / 判断 / 证据 / 对比 / 步骤 / 清单 / 数据 / 结尾

### P2｜观点短名
- 来源：
- 关键证据：
- 逐字文案：
- 页面任务：

## 未入选的重要内容

### X1｜内容短名
- 原因：为什么不进入图卡
- 去向：帖子正文 / 配套文案 / 后续系列 / 明确不采用

## 媒体去向

- 图片 1：正文 P2 / 改作封面 / 不采用及理由
- 截图 1：正文 P3；必须完整可读
- 短视频 1：动态图片槽 P4；起点、时长、裁切重点

## PAGE 1｜封面

- 观点：中心判断与阅读承诺
- 来源映射：P1
- 页面结构：type / split / image-led
- 逐字文案：
- 视觉证据：

## PAGE 2｜单一观点

- 观点：P2 的一句话主张
- 来源映射：P2 / 主稿第 X–Y 段
- 页面结构：statement / evidence / comparison / steps / list / data / closing
- 逐字文案：
- 视觉证据：
```

### 摘要纪律

1. 每张正文页只允许一个主观点；证据、步骤和例子只能服务该观点。
2. 所有入选观点必须映射回来源，但不要求原文全部进入图卡。
3. 未入选的重要内容必须写明去向，不能静默删除。
4. 页数由观点数量决定，不为凑页数制造观点、标签、数据或装饰信息。
5. 观点太多时先压缩选择或拆系列，不通过缩小字号塞进同一页。
6. 结尾回到中心判断，不临时新增教程、行动清单或营销号召。
7. 动态图片槽只使用用户已经选定的短视频；视频不合适时返回素材选择，不自动剪长视频。

## 摘要页数参考

- 3–5 页：单一判断、短案例或轻量观点。
- 5–9 页：完整视觉摘要。
- 超过 9 页：检查是否存在次要观点或可拆系列。

页数只是摘要模式的节奏参考，不是文章模式的删减依据。
