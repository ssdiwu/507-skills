# 小红书图文（rednote）

`507-rednote` 把已经成立的书面作品编辑为小红书图文。用户只说“小红书图文 / 图卡”时，默认先把原文排成一篇连续文章，再把阅读画布切成图片；物理页面不承担观点选择。明确要求视觉摘要时，才提炼为一页一个观点。

文章模式先确认唯一主稿，逐段核对内容完整并沿原顺序组织连续内容流，通过本地动态工作台把 `content.md` 与三轴 `visual-plan.json` 编译为 1500×2000 的 3:4 封面和正文页；封面图片可直接上传，正文图片上传后会作为标准 Markdown 插到当前光标并保存在作品 `assets/`。runtime 原样内嵌可商用、可再分发的 SIL OFL 1.1 思源黑体/宋体，字体可显式切换，字符占用宽度参与真实换行。浏览器按最终 DOM 的实际尺寸生成物理页面，Agent 不手写页码或页面内容来代替测量。摘要模式仍在明确要求提炼时启用。用户提供已经选定的短视频时，可把某页图片位置变成动态图片槽，生成整卡 MOV 并通过外部 `makelive` 打包 Live Photo；需要公众号封面时，可额外生成独立构图的 2100×900 主封面、1080×1080 分享封面和组合预览。

文章页数不是估算值：runtime 在最终 PageShell DOM 中测量并生成 `paged-content.json`；只有分页产物、manifest（清单）、实际图片和联系表页数一致且旧页清除后，才算完成页数变更。

## 目录

- `SKILL.md`：触发、全文 / 摘要模式合同、流程、边界与验收。
- `references/`：平台稿、三轴视觉、项目状态和视觉复核方法。
- `assets/visual-plan.schema.json`、`assets/paged-content.schema.json`：当前视觉与真实分页契约；`rednote-project.schema.json` 仅供旧规格迁移。
- `runtime/`：离线浏览器 bundle、OFL 本地字体、三栏工作台、语义编译、三轴 Resolver 与 DOM 分页器。
- `open-rednote.command`：macOS 可双击启动器；选择作品目录后启动本地服务并打开真正工作台。
- `scripts/`：工作台服务、同源导出、旧规格迁移、媒体合成、Live Photo 打包、尺寸检查与清单生成。
- `third-party-notices.md`：外部生成/验证工具的来源与许可证状态。

本 skill 不负责长文成稿、长视频剪辑、实况拼图、公众号正文或平台发布。缺少静态素材时使用独立素材能力；发布需另行授权。
