# 小红书视觉摘要（rednote）

`507-rednote` 把已经成立的书面作品提炼为一页一个观点的社交视觉包。

它先锁定中心判断、入选观点、来源映射和未入选内容去向，再为每页选择显式页面结构，以编辑杂志或瑞士国际主义视觉系统生成 1500×2000 小红书图卡。用户提供已经选定的短视频时，可把某页图片位置变成动态图片槽，生成整卡 MOV 并通过外部 `makelive` 打包 Live Photo；需要公众号封面时，可额外生成独立构图的 2100×900 主封面、1080×1080 分享封面和组合预览。

## 目录

- `SKILL.md`：触发、视觉摘要合同、流程、边界与验收。
- `references/`：Copy Spec、双视觉系统、项目规格和视觉复核方法。
- `assets/rednote-project.schema.json`：渲染输入契约。
- `scripts/`：样式预览、本地 HTML、Chrome 截图、媒体合成、Live Photo 打包、尺寸检查与清单生成。
- `third-party-notices.md`：外部生成/验证工具的来源与许可证状态。

本 skill 不负责长文成稿、长视频剪辑、实况拼图、公众号正文或平台发布。缺少静态素材时使用独立素材能力；发布需另行授权。
