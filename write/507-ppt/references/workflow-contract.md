# 视觉幻灯片工作流合同

## 上游：507-stage

`507-stage` 负责把已确认的内容组织为现场讲述或逐页内容。进入 `507-ppt` 前，每页至少应有：

- 页面认知目标；
- 观众可见标题与正文/图表/素材说明；
- speaker notes（讲者提示）或明确的“无备注”声明；
- 受众、场景、时长和内容边界。

内容仍在争论、页面认知目标不明、事实不足或讲者与观众信息未分离时，不能进入视觉制作，必须返回 `507-stage` 或其上游。

## 本 skill：507-ppt

`507-ppt` 只负责把成熟逐页内容制作为可演示视觉成品：

- 明确选择 HTML 或 `.pptx` 时尊重该选择；
- 未指定时探测 officecli：可用则优先 `.pptx`，不可用则生成单文件 HTML；
- 选择瑞士风或杂志风，并按对应风格合同渲染；
- 生成产物、speaker notes、素材替代文本和可复验验证清单；
- 发现内容缺口时停止视觉扩写并回退到 `507-stage`。

它不写讲稿、重排论证主线、做小红书图卡、自动发布或安装缺失依赖。

## 相邻 skill

| Skill | 负责 | 交接边界 |
| --- | --- | --- |
| `507-stage` | 讲稿、课程稿、逐页认知台阶 | 成熟逐页内容包 → `507-ppt` |
| `507-ppt` | HTML / `.pptx` 视觉演示成品及验证 | 内容缺口 → `507-stage`；视觉成品 → 用户交付或继续迭代 |
| `507-rednote` | 3:4 小红书图文改编 | 不消费或生成横向演示 deck，除非另有已锁定的改编合同 |

## 完成信号

输出载体可打开，内容与输入包对应，选择的风格在视觉上可辨识；HTML 或 `.pptx` 的相应验证均通过，且验证清单与产物一起交付。

## 回退条件

- officecli 不可用且用户未明确要求 `.pptx`：退回单文件 HTML；
- officecli 不可用但用户明确要求 `.pptx`：说明缺失能力，不自动安装，等待用户提供环境或改选 HTML；
- 浏览器、WebGL、字体或素材不可用：输出已有的静态/降级结果并明确缺失项；
- 内容、来源授权或许可证不清：停止制作，回到上游补齐。
