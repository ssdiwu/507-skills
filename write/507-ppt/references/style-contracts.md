# 视觉方向合同

风格合同定义可观察的视觉意图；`design-system.md` 定义组件和可组合设计令牌。HTML 和 `.pptx` 必须各自实现这些意图，不要求像素级相同。

## 共同约束

- 一页只服务一个已经确认的认知目标；
- 字体、色彩、网格、图片和留白承担信息层级，不用装饰掩盖内容缺口；
- 观众可见文字、speaker notes、图片替代文本彼此分离；
- 每页至少有一个视觉锚点：主标题、图片、数据、引用、流程或对比之一；
- 正文、图片和导航在静态/降级模式仍可读；
- 色彩满足文本对比度与投影可读性要求。
## 设计令牌

每个公开方向必须同时提供纸面色、正文色、强调色、中文/拉丁/元数据字体、形状圆角和密度。令牌只改变视觉表达，不得改变页面 ID、内容字段、notes 或素材语义。`swiss` 与 `magazine` 是原有方向；`cobalt`、`clay`、`forest` 与 `noir` 扩展技术、温暖、研究和声明表达。

## 瑞士风

**适用**：事实、产品、分析、方法论、数据驱动表达。

**意图**：冷峻、精确、信息优先。无衬线字体承担标题与正文；单一高饱和锚点色只标记重点；直角、发丝线、编号、严格对齐和清晰比例制造秩序。

**必须可观察到**：

- 标题、正文、编号/metadata 有至少两个等级的字号或字重对比；
- 单页只有一个主锚点色，非重点内容保持中性；
- 图文、卡片、数据和分隔线落在明确网格；
- 不使用圆角、投影、渐变或装饰性玻璃卡片替代结构；
- 信息页优先复用已验证的封面、声明、图文、对比、数据、流程或收束版式。

## 杂志风

**适用**：叙事、品牌、人文、设计、观点表达。

**意图**：温暖、编辑式、具有阅读节奏。衬线标题与无衬线正文分工；主题色克制点题；chrome、kicker、caption 与留白形成杂志的编辑层级；浅底与深底页面交替制造节奏。

**必须可观察到**：

- 标题使用衬线中文/拉丁角色，正文使用清晰无衬线角色，metadata 使用等宽或明显辅助角色；
- 主题色只用于 kicker、引用、短线、编号或少量重点；
- 图文页有明确的标题/正文/佐证或 caption 层次；
- 至少在需要时使用深浅页面节奏、编辑式元数据或 pull quote，而非把瑞士风仅换成暖色；
- 图片与文字遵从非对称编辑网格，并保留足够留白。

## 载体映射

| 意图 | HTML | `.pptx` |
| --- | --- | --- |
| 字体角色 | CSS font-family stack 与 fallback | 中文/拉丁/等宽字体分槽 |
| 网格与留白 | CSS grid/flex、相对尺寸 | 绝对坐标下的可复验对齐与最小边距 |
| 色彩 | CSS 变量与对比度检查 | HEX 色与 shape/font 属性 |
| 图片语义 | `alt`、`figcaption` | picture alt text、caption shape |
| 讲者提示 | 可选隐藏 presenter data | speaker notes |
| 动态 | DOM 语义外的装饰层与静态 fallback | 不作为首批风格定义的一部分 |
