# 组合与视觉质量合同

本文件检查“语义组件 × 设计语言 × 视觉呈现”组合是否真正成立。命名 preset 只记录已验证组合，不替代三个维度的独立合同。

## 共同要求

- 一页只服务一个已确认认知目标；
- 字体、色彩、网格、素材、图表和留白承担层级，不用装饰掩盖内容缺口；
- 页面至少有一个清楚主角；组件自身已有强结构时抑制重复线条、卡片或纹理；
- 同一基础语言的字体角色、轮廓、色彩行为与间距节奏跨页一致；
- 视觉呈现可以逐页变化，但不能把同一 deck 变成多套互不相关语言；
- 中文换行、对比度、投影距离和素材清晰度以最终截图验收。

## 设计语言可观察信号

| 语言 | 至少应观察到 | 不应被误认成 |
| --- | --- | --- |
| precision-modern | 严格对齐、直角、无衬线/等宽分工、单一强调、平面层次 | 所有内容都装卡片的蓝色主题 |
| editorial-archive | 衬线/无衬线/等宽层级、栏栅格、hairline、暖纸和编辑节奏 | 暖色 dashboard |
| soft-product | 圆润轮廓、轻抬升、舒展模块、人文无衬线与柔和状态色 | 玻璃发光或玩具化图标堆 |
| warm-narrative | 非对称叙事节奏、暖色、衬线标题与纸面感 | 仅把 editorial 换成橙色 |
| research-organic | 研究型层级、克制自然色、稳定模块与低装饰 | 绿色卡片模板 |
| bold-statement | 大字、强对比、粗规则线与单一高能标点 | 每页都用同一种口号海报 |

## 呈现质量

- `type-led`：文字本身是主视觉；短标题能一行则一行。
- `panel-led`：容器服务分组，不让卡片数量等同组件语义。
- `data-led`：数字关系、尺度、单位和来源可查；chart/table 使用原生可编辑对象。
- `schematic-led`：节点、边、顺序或层级可读，装饰线不能伪造关系。
- `photo-led / ui-product-led`：真实授权素材承担证据，图像不是占位装饰。
- `editorial-print-led`：通过栏、规则线、caption 和节奏成立；PPTX 适配不烘焙不可编辑纹理。
- `hand-drawn-explainer`：手绘只改变表达语气，不改变关系事实；PPTX 适配必须明示。

## 组合冲突

解析器至少处理：稀疏与高密度、锐利与圆润、平面与材质层、近单色与多强调、photo/data/illustration 对主角的竞争。

已验证规则：`precision-modern + table + ruled table` 抑制背景网格和装饰规则线，保留 table 自身行列边界。发现新冲突时先以真实内容原型验证，再把通用结论加入注册表；不为单次审美意见扩大全局硬规则。

## 载体映射

HTML 与 PPTX 不要求像素相同，但组件、语言、呈现主张与阅读顺序要一致。载体适配必须保留可编辑文本/shape/chart/table/picture；任何简化进入 manifest degradation，不能用“风格相近”掩盖能力缺失。
