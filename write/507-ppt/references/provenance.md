# 来源与许可证合同

`507-ppt` 的完成依据是当前仓库、产物和命令输出，不包含历史访问或法律认证结论。

## 当前实现来源

每个新增的运行时代码、第三方依赖、图片、字体或二进制资产，必须在 `../third-party-notices.md` 中有一行记录：

| 字段 | 要求 |
| --- | --- |
| 名称 | 稳定名称或资产 ID |
| 版本 | 精确版本、提交或内容版本 |
| 来源 | 官方 URL 或项目内原创文件路径 |
| 许可证 | 可核验 SPDX 标识或原创声明 |
| 用途 | 解决的具体能力缺口 |
| notice | 交付物中 notice 的相对路径或“不适用” |

项目内原创文件使用相对路径作为来源，并在生成 manifest 中列出 SHA-256。第三方运行依赖仅接受 MIT、Apache-2.0、BSD、ISC、CC0 或等价宽松许可证；不明许可证不能进入产物。

## 范围检查

每次生成前后执行：

1. 列出 HTML、CSS、JS、Python、PPTX、图片和字体文件；
2. 检查每个非生成文件均有来源/notice 记录；
3. 检查 HTML 不依赖远程 CDN；
4. 计算产物和本地素材 SHA-256；
5. 将检查结果写入产物 manifest。

范围检查只能说明当前仓库和产物的记录完整性；它不替代版权、许可证兼容或法律意见。

## 外部实现与旧 skill

`507-ppt` 不以外部演示 skill 的模板、验证器、版式编号、提示词或视觉资产作为项目内文件来源。风格以当前 `style-contracts.md` 的可观察约束实现。旧 skill 只有在本 skill 的 HTML/PPTX 样例、测试和备份恢复命令齐全后才移动到非发现备份目录。
