# HTML recipe

HTML 是离线可打开的单文件横向演示，不依赖服务端或 CDN 才能演示。当前生成器使用语义 DOM、原生交互和 Canvas 装饰层；验证由 `scripts/validate_html.py` 与 Chrome 截图命令执行。

## 语义与交互

- 标题、正文、图表说明和图片说明留在 DOM；
- slide 有可读标签和当前页状态；导航可通过键盘、按钮、滚轮与触控完成；
- 动态 canvas/WebGL 是绝对定位装饰层，不承载内容或导航；
- 禁用/失败 JavaScript、无 WebGL、静态模式和 `prefers-reduced-motion` 下仍可阅读和切换关键内容。

## 最小验证

1. 结构：页面 ID 唯一、索引连续、素材可访问、无未声明远程资源；
2. 交互：键盘、按钮、滚轮、触控和页码状态可复验；
3. 视觉：固定桌面/平板/移动视口截图，无文字裁切或失焦布局；
4. 退化：强制 WebGL 失败、静态模式、减少动态均保留可读内容；
5. 无障碍：焦点、标签、状态通知、文字对比度和键盘遍历合格；
6. 来源：任何内嵌依赖有许可证/notice，且可以离线运行。

## 动态层策略

优先标准 WebGL 或 CSS；只有标准能力不能满足已验证的 hero 视觉目标时，才选择记录在 `third-party-notices.md` 的宽松许可依赖。动画使用可固定的时间步或静态种子，以便截图回归。
