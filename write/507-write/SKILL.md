# 成文与修订（write）

把已有要求、材料或用户稿件写成指定的书面或口播产物。原 forge、frame、stage 的方法在本包中按用途提供；用户表达目标，agent 选择必要方法，不要求学习技能菜单。

## 选择产物和修改范围

| 目标 | 必读方法 | 产物与限制 |
| --- | --- | --- |
| 文章、博客、平台文案、已有稿件润色或重组 | [书面成文与修订](references/prose.md) | 主稿或指定部分修订；局部润色不触发整稿重排、材料回补或发布格式转换 |
| 活动、培训、合作或项目正式方案 | [方案成文](references/proposal.md) | 推动决策／行动的方案，保留角色、资源、时间、费用与未定状态；不自行承诺业务事实 |
| 演讲、课程口播、PPT 逐页内容或视频旁白 | [现场内容编排](references/spoken.md) | 讲稿或内容包，区分观众正文、备注与证据；不自动生成 PPT、配音、时间线或成片 |

先承接用户指定版本、已确认结论与当前稿。用途明确时直接完成，写法、章节和常规表达由 agent 判断；输出类型或实质责任仍影响用户目标时只询问必要缺口。只读建议不变成稿件写入授权。

只读本次模式及其条件参考；不会因同一技能支持其他产物而额外交付或混用其语言。用户确实需要文章转讲稿等连续工作时复用材料与已确认边界，按各自方法产出，不把一份正文机械改名。

## 共同合同

- 用户修订稿优先，精确保护数量、单位、权限、否定、例外、时限、责任与确定程度。建议、已确认要求、当前实现和实际验证分别表达。
- 不补造亲历、引语、数字、角色或用户承诺。作者／讲者的判断与声音来自真实材料，不靠凭空增加第一人称或夸张态度。
- 用户已经排除的方向退出当前作品，不用假平衡或换个场景重新引入。只有真实竞争解释或新取舍才重新对齐。
- 材料与篇幅、时长、页数相称，不靠同义重复填满目标，不因格式要求掩盖证据缺口。
- 资料可查先查，资料已充分时完成可通读首稿；逐段审批只在用户明确需要的协作方式中采用。工程、排版与措辞细节不转交用户决定。
- 真实、准备材料、待制作与未核验状态保持来源可追溯；对读者无帮助的制作过程放相应备注或证据位置，不冒充已发生结果。
- 交付核对当前模式的目标与成品，不把自动表达提醒当禁词表或语义验收。公开事实不足时补证或保留未知，不能让格式检查代替作者与内容判断。

缺尚未表达的一手材料可进入 prospect 后返回，已表达材料／观点不足可进入 mine，外部事实进入 research，真实主线竞争或用户取舍分别进入相应动作；不强制每次走完整素材链，目标环境没有相邻技能时使用等价方法。

阅读模式参考不取得额外副作用权限。账号登录、消息发送、平台发布、付费素材生成和 Git 动作都不包含在普通成文请求内。软件行为规格由 507-prd 维护，成熟视觉幻灯片由 507-ppt 制作，旁白配音与成片分别由 narrate／video 承接。

## 完成与接力

- **完成信号**：当前请求的文章、方案或口播产物按适用合同完成，读者、材料、表达和行动／理解目标一致；局部修订保留原意与声音，实质未知没有伪装成定案。
- **产物**：用户指定位置或项目现行作品位置中的主稿、精确修订或明确状态的草稿，附必要含义风险和未覆盖边界。
- **候选出口**：材料／事实／实质决策缺口补齐后返回；成熟内容进入用户要求的视觉、配音或视频动作；仅成文本身即目标时结束，不自动发布。
- **回退条件**：关键事实、作者位置、责任承诺或内容主线仍未成立时，保留当前稿并说明最小缺口；不以视觉包装、自动提醒绿灯或临时猜测替代内容完成。
