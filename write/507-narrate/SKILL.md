# 本地配音生成（507-narrate）

把成熟、可说的旁白正文转换成**经过授权、真实生成、可复验并能交给视频时间线使用的本地配音包**。当前确定性 adapter（适配器）使用 Voicebox 的本地 REST API，不配置 MCP。

运行前读 [目录说明](README.md)；调用脚本、选择模型或准备批量输入时读 [脚本说明](scripts/README.md)。

## 不覆盖什么

- 不写、改或收口口播内容；旁白未成熟时进入 `507-stage`。
- 不录制、导入、创建、删除或共享声音档案；首次声音采集和试听确认留在 Voicebox 界面。
- 不制作画面、字幕样式、时间线或成片；配音包交给 `507-video`。
- 不登录、上传或发布到外部平台。
- 不把 Voicebox Stories、MCP 或内部 server binary（服务端二进制）变成第二套工作流。

## 输入门

开始生成前至少具备：

1. 成熟旁白正文；批量任务有稳定、唯一的 section ID；
2. 声音档案属于用户本人，或说话者已明确授权当前用途；
3. Voicebox 已安装，目标声音档案已由人试听确认；
4. 语言、交付位置，以及是否需要覆盖默认 preset（预设）、语速、语气指令或 seed（随机种子）；
5. 事实、隐私和公开边界已从上游继承。

缺少用户拥有的声音授权或声音身份选择时停止并询问；工程参数由 agent 先读取 live capabilities（实时能力）和声音档案默认值后收口，不让用户猜可用组合。

## 工作流程

### 1. 归一旁白版本

- 保存正文版本或输入文件哈希；删除不能被朗读的标题、列表标记和来源注释。
- 批量任务保持 `507-stage` 的 section ID；发音说明通过旁白文本或引擎支持的 instruct 传入，不污染观众字幕正文。
- 旁白正文变化后，旧音频、时长、字幕和下游审片确认全部失效。

### 2. 核验声音授权与档案

- 每次生成都显式确认 `--authorized-voice`；没有本人所有权或明确授权不继续。
- 只读取现有声音档案。存在多个档案时按精确名称或 ID 选择，不靠列表顺序猜测。
- 声音档案 ID、样本、录音和生成历史属于本地敏感资料，不写入公开仓库。

### 3. 选择引擎与模型

- 先运行 `capabilities` 读取当前 Voicebox 实际接受的 engine、model size 和 language，不在 skill 中固化易过期清单。
- engine、声音档案类型、语言与 model size 必须兼容；接口接受某个枚举值不等于任意组合都成立。
- 未指定时使用 `daily`：Qwen 0.6B，最终 `1.2×` 保留音高加速，适合日常旁白。
- 需要更清楚的咬字时使用 `precision`：Qwen 1.7B，最终同样默认 `1.2×` 保留音高加速。
- 两个 preset 都允许显式覆盖 engine、model size 或 speed；改用其他引擎前先以同一句短样本做最小 A/B，再锁定整批参数。
- 加速会压缩停顿，但不会修复错误断句；日常旁白优先使用短句和明确标点。
- 同一批配音保持 engine、model size、语言和基础后处理一致；有意改变时新建可区分版本。

### 4. 检查或启动服务

- 默认只连接 loopback（本机回环）地址；非本机服务必须有显式信任和 `--allow-remote`。
- 先检查 `/health`；macOS 本机离线时由脚本启动 Voicebox 应用并等待健康，不直接调用应用包内的私有 server binary。
- 不改变“关闭应用后保持服务器运行”等用户设置，也不在完成后擅自关闭既有服务。

### 5. 生成与等待

- 新档案、引擎或模型组合先生成一段短试听；音质、相似度和语气需要人听，文件存在不能替代听感确认。
- 正式任务按 section 顺序生成。`POST /generate` 返回任务后，读取 SSE（服务器事件流）直到完成、失败或超时，再下载音频。
- 下载后的原始 WAV 通过 FFmpeg `atempo` 做保留音高变速；默认 `1.2×`，最终 WAV 才是时间基准。
- 不把文字估时或 Voicebox 原始时长当最终时间；每段以变速后 WAV 的实际帧数计算时长。

### 6. 验证与交接

- 核验最终 WAV 可解析、帧数和时长大于零、采样率/声道明确、文件哈希已记录，并保留原始时长、最终速度与保留音高标记。
- 批量输出以真实段落时长累计 start/end，形成 `narration-manifest.json`；当前只承诺段落级 timing，不伪造逐字时间戳。
- 报告使用的声音档案、engine、model size、语言、生成结果、已知限制和需要用户试听的位置。

## 硬门

- 未确认声音所有权或明确授权，不生成。
- 不因 Voicebox 软件采用开源协议就推定声音、模型或发布用途自动获权。
- 不把自动转写近似正确称为声音相似度或听感验收通过。
- 不覆盖既有音频或 manifest，除非用户明确允许替换并传入 `--force`。
- 不上传声音样本、声音档案、生成音频或本地 manifest 到公共仓库。

## 完成与接力

- **完成信号**：所有目标 section 均已生成；WAV 通过结构验证；manifest 记录真实时长、参数、哈希和完成状态；需要听感判断的版本已交给用户试听。
- **产物**：单段 WAV + manifest，或分段 WAV + `narration-manifest.json` 配音包。
- **候选出口**：正文需改动时返回 `507-stage`；需要画面、字幕与成片时进入 `507-video`；只需独立音频时直接交付；需要外部发布时等待用户另行明确授权。
- **回退条件**：服务不可用、档案不存在、组合不兼容、生成失败、音频不可解析或用户否定听感时，保留错误证据和可恢复产物，不宣称配音完成。
