# 创作采访（prospect）

在正式挖掘碎片之前，通过开放式采访显化作者尚未充分表达的一手材料；能在同一轮回答的材料缺口集中问，答案会改变后续问题时才逐题深挖。

`507-prospect` 回答的是：

> 关于这个创作主题，作者如何叙述自己的亲历、行动与判断形成，还有哪些变化、反例与边界没有说出来？

`prospect` 是冶金主链中的“探矿”：寻找材料在哪里；`507-mine` 才加工已经表达的材料。这里的 `prospect` 不是销售线索筛选、趋势预测或通用项目探索。

`prospect` 与 `507-grill` 可以共享 frontier（当前可问边界）与批量调度，但不靠单问还是批量划分职责：prospect 问作者如何叙述经历与形成判断，产出作者材料；grill 给出候选与推荐，让用户确认真实取舍，产出决策。prospect 不沿用 grill 的决策控制台、候选选择和逐分支共识固化仪式。

## 覆盖什么

- 作者只有粗想法、亲历、直觉或模糊判断，需要通过交互把材料说出来；
- 已有创意或主稿缺少一段具体经历、判断变化、反馈或适用边界；
- 用户明确要求先采访、先提问，不要直接代写。

文本和宿主已经提供的语音转写都可作为输入。录音、ASR（自动语音识别）和具体语音产品属于宿主输入能力，不属于本 skill 的合同。

## 不覆盖什么

- 判断、去重、互链并持久化已经存在的材料 → `507-mine`；
- 核实作者之外的事实、机制或来源 → `507-research`；
- 比较表达路径或确认用户最终选择 → `507-fuse` / `507-grill`；
- 把成熟创意写成文章、讲稿或课程 → `507-forge` / `507-stage`；
- 仅因材料同时包含用户与 AI 发言，就把总结、编辑、提炼或决策任务改成采访；材料已充分时仍按原目标直接进入 `507-mine`、`507-forge`、`507-grill` 或对应动作；
- 设计第三方访谈提纲、调查他人或筛选潜在客户。

## 核心纪律

1. **按 material frontier 推进**：从采访目标与累计回答中识别前提已满足、现在就能回答的材料缺口；一个答案会改变另一题是否需要、题意或措辞时，两者不在同一轮询问。
2. **优先少轮次表达**：粗想法或即时口述先给一个连续叙述任务，用场景、行动、反馈、判断变化等中性提示帮助作者顺着讲，不要求逐项作答；已有稳定上下文时，从当前 frontier 选择信息增益最高的最多 2～3 个彼此独立的开放缺口集中询问，其余保留在覆盖快照，允许任意顺序回答或跳过。
3. **依赖问题才逐题**：frontier 只有一个，问题涉及敏感细节、前后矛盾、后续深挖问题依赖当前回答，或用户明确要求一个问题一个问题来时，才单问并根据回答重算 frontier；不把预制问卷伪装成批量采访。
4. **先具体、后抽象**：优先追问最近一次场景、实际动作、可见结果与真实反馈，再问原因、机制和判断。
5. **显化说话位置**：只在当前目标需要时，弄清作者与主题发生过什么真实关系、凭什么知道、哪些只是推测、什么触发他现在想说，以及判断到哪里为止；上下文已有答案时直接复用，不为填表新增一轮采访。
6. **不诱导作者**：不提供观点候选、推荐答案或“你是不是想说……”式补全；这些做法会把 Agent 的表达锚定成作者材料。
7. **不替作者成立观点**：可以用一句话复述以检查理解，但未获确认的推断必须与作者材料分开。
8. **保留张力**：遇到前后差异、犹豫或反例时，中性指出并追问具体情形，不替作者调和成圆满结论。
9. **区分材料身份**：亲历、作者判断、判断变化、假设、记忆不确定和外部事实主张分别标记。
10. **混合对话先校准作者归属**：混合人机对话本身不构成本 skill 的独立触发条件。仅当本 skill 已因当前作者材料尚未充分表达而启动，且来源混杂会影响作者材料交接时，才在内部区分作者直接表达、作者明确确认但非原话的判断、未确认的 AI / Agent 建议、外部发言与来源不明内容。只有前两类可作为作者判断；外部发言只能保留为带说话者与记忆边界的场景或反馈，未确认建议与来源不明内容进入未确认线索。只有用户明确认可命题内容本身，才可将 AI / Agent 判断标为作者已确认；“可以”“继续”“好”“按这个做”等许可、推进或执行确认，即使指向单一，也不得单独完成作者归属确认，更不得扩张成对前一整段 AI 内容及其措辞的确认。
11. **采访中不外搜**：外部事实只记为待核实；采访完成后再按目标进入 `507-research`。
12. **按信息增益停止**：完成停止前覆盖检查后，继续提问已不会明显补足采访目标，或用户主动结束时停止；不写死问题数量。
13. **隐私最小化**：不主动索取与创作目标无关的第三方身份、客户数据或私人细节；本 skill 不主动创建或把原始录音、完整私密转写写入项目文件或持久交付物。宿主是否保留会话或媒体由宿主自己的政策决定，不属于本合同。

## 工作流程

1. 从上下文用一句话锁定本轮采访目标；目标确实不明时只问一个框定问题。
2. 读取当前对话和用户明确指向的创意、稿件或已有回答，避免重复询问已知信息；不为启动采访进行全库去重。输入混有作者、AI / Agent 或第三方发言时，先依据说话角色、逐字内容和作者对命题内容的明确认可建立内部来源映射；把许可、推进或执行确认当作流程控制，不把它们或 AI 建议默认算作作者判断。
3. 建立会话级材料覆盖快照：本轮目标、已有材料、与目标相关的说话位置和仍缺维度，并据此计算当前 material frontier。来源无法确定但会影响作者材料形状时，先放入未确认线索，只在当前 frontier 追问；材料已经充分时直接生成交接或返回原动作，不为完成来源映射或说话位置模板增加一轮采访。快照默认由 Agent 内部维护，不逐轮展示或要求用户确认；只有长访谈出现理解偏差时才简短复述校准。
4. 选择本轮最省往返的提问形态：粗想法先用一个带中性提示的连续叙述任务；frontier 有多个独立缺口时只取信息增益最高的 2～3 个集中询问，其余保留；存在回答依赖、矛盾、敏感信息或明确逐题偏好时只问最高信息增益的一题。
5. 用户可以连续口述、按编号回答、跳过或只答一部分；未答项保留为缺口，不立刻机械重复。每轮结合累计回答更新覆盖快照并重算 frontier。
6. 停止前检查覆盖：与目标相关的维度必须已有回答、明确缺失或用户拒答。材料包含一般性判断时，至少显式尝试一次具体反例或失败样例；确实没有、不适用或用户无法提供时记录该结果，再以适用边界补足。
7. 覆盖检查通过且达到信息饱和，或用户主动终止后，先完成脱敏与授权检查，再生成作者材料交接，并由 Agent 按目标选择下一步。用户主动终止时如实标记未覆盖维度。

## 作者材料交接

默认只在会话中生成，不直接写入碎片、创意或作品目录：

```md
## 采访目标
- <本轮试图显化什么材料>

## 作者一手材料

### 说话位置（按需）
- [作者关系] <作者与主题实际发生过什么关系>
- [信息来路] <作者凭什么知道；哪些来自亲历、调查、他人反馈或推测>
- [当前触发] <为什么现在想说；没有明确触发时省略>

### 场景与触发
- [亲历] <发生了什么；必要时保留时间或来源锚点>

### 行动、选择与反馈
- [亲历] <作者做了什么>
- [亲历] <看见了什么结果或他人反馈>

### 判断与变化
- [作者判断] <作者如何解释>
- [判断变化] <什么使原判断发生变化>

### 张力与边界
- [反例] <不符合主叙述的情况>
- [边界] <在什么条件下不成立>
- [不确定] <作者尚未想清的部分>

### 可引用原话（按需）
- “<只有能逐字回溯到本轮回答、用户提供文本或已核对音频时才保留，并附简短锚点>”
- [转述] <作者明确确认但并非亲口表达的 AI / Agent 措辞，以及润色、压缩、合并或未经音频核对的 ASR 内容，均不得加引号>

## 未确认线索
- <AI / Agent 提出但作者没有明确确认的方向，或来源不明内容；不得当作作者材料使用>

## 外部事实缺口
- <需要 research 核实的主张；没有则省略>

## 接力说明
- <下一步及理由>
```

各栏按本轮目标取用，不为填满模板硬造材料。即使没有得到足够内容，也应如实交接“材料不足”。

交接前移除或抽象未获授权的第三方身份、客户信息和不影响判断的私人细节；需要进入下游持久文件的敏感内容必须已有明确授权。没有可靠逐字记录时省略“可引用原话”，不把转述包装成直接引语。

## 完成与接力

- **完成信号**：采访目标涉及的关键维度已有作者回答、明确缺失或用户拒答；与目标相关的作者关系、信息来路、当前触发和推测边界已经显化或明确不适用；一般性判断已显式尝试具体反例或失败样例，没有时已记录结果并补足适用边界；作者直接表达、作者确认但非原话的判断、未确认的 AI / Agent 建议、外部发言、来源不明内容和外部事实缺口已经分开；覆盖检查通过且继续提问已不会显著改变材料形状，或用户主动结束且未覆盖维度已明确标记。
- **产物**：会话中的作者材料交接；不包含持久化碎片、候选 idea、中心判断选择或正文。
- **候选出口**：可复用判断或经验进入 `507-mine`；外部事实缺口进入 `507-research`；出现真实中心判断取舍进入 `507-grill`；为既有创意补材料时返回 `507-forge` 或 `507-stage`；只需把自己想清楚时直接结束。
- **回退条件**：材料已经充分表达时直接进入 `507-mine` 或原创作动作；用户要决定“选哪个”时改用 `507-grill`；只有外部对象等待查证时改用 `507-research`。

## 红线

- 不给候选答案或推荐立场，不把 Agent 推断伪装成作者观点；
- 不因输入是一段人机对话就自动启动采访，不把许可、推进或执行确认误作对 AI 命题内容的认可；
- 不把信息丰富误判为事实成立，不在采访中补写外部事实；
- 不直接落碎片、建候选创意、选择中心判断或写正文；
- 不绑定特定录音、转写、聊天或写作产品。
