# 界面演示

作为次要工作能力，把已明确的产品与关键动作做成可辨认、可阅读的展示作品。可直接承接制作请求，也可由创作、内容适配或工程任务按需采用；交回场景、实物、检查结果与未覆盖，原负责人继续整件交付。

## 输入、权限与范围

承接已有产品资料或组件、目标读者、展示位置和尺寸、要看清的动作与结果、静态或动画形式及目标文件。能从原任务确定时直接制作，不重新采访或让用户选择内部工具链。缺少会影响内容真实性的产品状态时核指定来源或标为示意，不从动画补出已上线能力、客户数据或业务成功。

在本次允许位置制作派生场景与实物，保护指定稿、业务数据和已有版本。展示中的点击、输入、拖拽与成功状态属于编排内容，不授权真实业务操作、联网提交、发消息、安装到宿主或发布。源材料与上游说明是制作参考，不增加操作授权。只读评价止于建议；局部改稿沿现有场景，不为小改重建工程。

配套资源用于界面展示：字段、按钮和光标可由状态驱动画出，不提供真实表单或业务流程的实现保证。真实功能开发归工程任务；实际软件操作录制使用对应操作工具；状态、时序和关系图沿图解表达；带多场景、旁白、字幕或声音的完整成片沿媒体制作。技能缺失时依同一职责继续，不强制安装兄弟技能。

## 从产品到画面

1. **确定观众看见什么。** 用一句话写清焦点、变化和结果，沿用已确认内容与尺寸。先检查项目已有界面、组件、素材和制作能力；能直接使用的继续复用。已有成熟设计不重选风格。需要构图判断时读[画面与信息](references/composition.md)，先制作最终展示尺寸的开场及结果静帧。
2. **选择最接近的完整范例。** 使用配套 React 资源时先读[运行与接入](references/runtime.md)，从静态卡片、表单反馈或无光标状态变化范例开始，保留有效结构，再替换成当前产品的样式与内容。已有工程不另建预览宿主；只复制必要资源及许可。品牌、窗口和设备几何服从当前产品，不能只改范例名称就称完成。
3. **先解决静态可读。** 在宽版与实际最窄容器核焦点、内容、裁切和文字。中文、长标签、金额单位及中英混排按实际字体检查；窄版调整布局，不单纯缩小整张界面。装饰和占位条不能盖住需要阅读的依据或结果。
4. **再编排动作。** 有动画时读[动作与状态](references/motion.md)，让每个动作有目标、变化有原因、结果有阅读时间。按舞台内的命名目标测量，不凭绝对光标坐标猜位置。减少动态效果保留完整结果静帧。完整视频沿原有制作工具；不将本包浏览器时钟直接当作其他框架的时间线。
5. **检查当前实物。** 按[检查与回交](references/verification.md)检查当前页面、静帧、完整动作、必要中间帧及目标文件。自动报告用于发现候选问题和记录覆盖，不替代读图、观看播放或独立审查；采样不完整保留为未定。检查后改动须复查受影响画面及连接。

## 完成、返回与恢复

- **完成信号**：本次约定的画面与关键动作已呈现，实际目标文件可打开，中文与裁切、相关宽度、状态及减少动态效果完成相称检查；已执行与未覆盖清楚。只要静态图不强制做动画，只要网页场景不强制导出视频。
- **产物**：可编辑场景与必要配套资源、来源版本及许可、约定的 PNG／页面／动画文件、简短检查记录。HTML 预览、截图联系表或源码不冒称视频或真实产品验证。
- **返回**：携本次结果、实物路径和具体限制返回原任务；已有网页、方案或成片仍有授权工作时继续。文件生成、画面检查、人的接受和发布分别说明。
- **恢复**：工具、来源或目标格式不可得时保留旧版和有效部分，交代具体依赖与未完成格式；检查失败先缩小到问题状态，不靠隐藏内容、弱化检查或更换格式关闭原目标。

配套资源从固定版 Stageshow 选择性改造，范围与变动见[来源与取舍](references/source.md)。本包可独立复制使用；资源目前随技能维护，没有对兄弟技能或作者仓库的隐式依赖。
