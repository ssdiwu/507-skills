# 运行与接入

首次使用本包 React 组件或检查脚本时读本页。`runtime/` 是独立可复制资源，含固定版组件、少量范例、隔离预览和检查脚本；不是已安装的全局工具。来源见[取舍说明](source.md)。

## 在新位置运行

需要 Node.js 20.19+、npm；截图检查另需本机 Chrome，或通过 `CHROME_PATH` 指定兼容浏览器。目标已有相容工程时优先接入现有组件和依赖，不另装一套宿主。新预览在允许的新目录中复制 `runtime/` 后，从该目录执行：

```sh
npm ci --ignore-scripts
npm run typecheck
npm run dev
```

依赖安装访问 npm 并写本地 `node_modules/`；仅在本次制作授权与环境允许时执行。不改全局配置、不安装 portless 或浏览器；依赖／浏览器不可得时说明具体缺口。预览默认只监听 `127.0.0.1:5173`，端口占用会失败；可显式换空闲端口，不结束其他进程。

打开预览地址，选择场景。宽版／窄版、播放／暂停、逐帧、重播与静态结果用于检查画面，窄版预览不代表真实触摸已验。选择和播放按钮是宿主真实控件，场景内部的输入与按钮是演示内容。单场景的直接路径如 `/?capture=review-flow` 使用原生时钟，供截图工具或真实宿主检查；普通预览使用隔离 iframe。

## 放进现有工程

复制 `kit/` 和要使用的场景文件，保留各自 CSS、MIT 许可及来源记录。组件入口为 `kit/index.ts`，运行依赖 React、react-dom 与 lucide-react；预览／检查依赖不是组件运行依赖。使用当前产品的组件时可以只保留 Stage 与动作层，不为保持范例外观替换产品设计系统。

配套 kit 移除了品牌标识注册表、BrandMark 与应用图标素材；需要品牌时使用产品已有且允许使用的资产。字段 `Field`、图标按钮和模拟点击不提供业务表单语义，真实功能另行实现并验证。组件 API 按所用条目查 [Kit](../runtime/references/kit.md)；文中的 BrandMark 条目属于未携带的上游能力，不能直接调用。

## 文件与副作用

- `npm run build` 将预览构建到 `playground/dist/`；不要把构建目录或依赖纳入技能源码清单。
- `npm run check:css` 只检查范例 CSS 的命名冲突候选，不修改场景。
- `scripts/film.mjs`、`layout.mjs` 等启动隔离的无头浏览器，读取给定页面并写指定截图／报告；不会操作用户的已登录浏览器，但页面自身仍可能有联网行为。使用本次受控页面，避免将带真实提交副作用的页面作为演示检查目标。
- 截图与报告工具可能覆盖同名输出；调用方先选本次唯一且尚不存在的证据目录，不覆盖旧成品。脚本失败保留原输出、错误与退出状态，再修依赖或输入。

具体检查步骤和结果解释见[检查与回交](verification.md)。依赖、构建、宿主接入与目标文件分别验证；不能只因本预览能打开就宣布目标项目接入通过。
