# What · 明确目标与关键取舍

把初步设想整理为可指导方案的问题定义，形成目标、范围、关键概念、成功标准和必要取舍。信息充分时直接返回原任务；不要求每个任务先过本技能。

共有依赖见[共有资源合同](../../lib/README.md)，按本文链接直接使用同一份资源。

## 输入与边界

承接原请求、已有材料、当前决定、用户修订和有效授权。先自行核实可查事实；实现、措辞和常规可逆技术选择由 Agent 处理。只向用户询问其拥有且尚未确定的目标、优先级、体验、责任、成本或风险取舍。

简单对齐可以在会话完成；持续定义主动维护当前项目中的目标、范围、成功标准、关键决定及原因、排除项和下一动作。只要求澄清时，交付后直接结束；原任务已经授权实施时返回并继续实施，不再追加“共同理解确认”关口。

本技能不自行实施产品、创建整套规格、发布或发送消息。持续定义的必要本地记录属于任务责任，无需另等用户要求；按[工作记录](../../lib/methods/work-records.md)维护唯一归处，明确只读、不写文件或临时讨论时遵守限制。建议、Agent 判断和用户决定分别标明，记录不使建议成为定案。

## 形成判断、建议与必要取舍

目标尚在形成、用户在讨论方向，或新材料显露遗漏的价值与机会时，主动提出自己的判断：可以重看任务背后的目的、被忽略的使用者或限制，质疑未经检验的前提，提出用户尚未想到但与当前问题有关的观点。不要等用户先列全选项，也不只复述请求或连续提问；已有材料足以形成有用建议时先给建议与理由。

把新观点明确写成Agent建议或待检验假设，说明它依据什么、可能改善什么、主要代价或成立条件，以及什么观察会改变判断；不能冒充用户动机、已定目标或已证实事实。无需每次凑新观点或走完四维；已有充分目标与方案直接承接，既定决定仅在前提变化或反证下复审，明确排除项保持。目标、优先级或实质成本风险的变化交用户决定，常规可逆选择由Agent继续完成。

当请求把某种载体当作解决办法而用途尚不明确时，补足读者或使用者接下来要理解、决定或完成的动作，再判断该载体是否足够。已有明确文件、格式和范围继续作为交付要求；更高层结果只用于校准方案，不自动替换用户目标、扩大业务范围或启动持续代办。已有目的和方案充分时直接沿用。

先整合已有材料、有效决定和排除项，提出当前可成立的定义，说明事实、判断与未决。缺事实就查证，缺设计就主动构造，必要时采用 how 的方案职责；需要组织依赖与检查点时按需采用 507-plan，缺少相邻技能按同一边界直接完成，不形成安装前提。意图或取舍需要进一步展开时，读[澄清与追问](references/conversation.md)：有依据先形成建议，确缺用户信息再用中性问题显化，真实取舍给可行候选与推荐；不把这些动作混成固定问卷。

| 当前缺口 | 按需方法及用途 |
| --- | --- |
| 事实、版本或来源有疑点 | [事实与证据](../../lib/methods/evidence.md)：自行核实，只冻结依赖未知事实的决定 |
| 分不清谁应该决定 | [决定归属](../../lib/methods/decision-ownership.md)：复用授权，收回应由 Agent 完成的设计 |
| 多个问题相互依赖 | [问题依赖](../../lib/methods/question-frontier.md)：先前提、后分支，独立问题可批量收集 |
| 有真实策略或优先级取舍 | [候选与反证](../../lib/methods/alternatives.md)：给成立条件、代价与推荐，不凑选项 |
| “完成”“更好”等目标不可观察 | [可观察验收](../../lib/methods/validation.md)：澄清可识别结果，区分偏好与事实 |
| 新决定冲突或需要返回、沉淀 | [权威与返回](../../lib/methods/authority-and-return.md)：核对取代关系与当前正文归宿 |
| 关系复杂、表达妨碍判断 | [清晰表达](../../lib/methods/clear-expression.md)：只展示当前需要理解的关系 |

`why` 用来按需澄清目的、价值和优先级；其余5W2H角度同样按缺口采用，不轮流问完。方法只解决相应问题，不自行启动新技能或执行所讨论的业务动作。

## 完成与返回

- **完成**：下一步所需的用户决定已足够；已确认内容、事实与假设可分辨；仍未确定的事项只保留真实影响。不要求走完预先列出的所有分支或完成工程设计。
- **产物**：与规模相称的对齐结论。简单问题一两句即可；复杂时包含目标、范围、决定、未决依赖与下一动作，不强制图或新文件。
- **返回**：继续原任务已有授权的工作。仅请求澄清时结束；进入技能规划或编写须原请求确有该目标，不能因为澄清产生方法就自动调用 `skill-design`。
- **恢复**：遇到事实缺口、矛盾或用户尚未回答，只暂停依赖部分；可推进的工作继续。用户新答复使旧问题失去必要性时删除该问题。

本次出现真实中断、上下文压缩或转交时核实际版本、写权、有效尝试与未完成；普通结束跳过时，读[真实中断、交接与续办](../../lib/methods/continuation.md)并在本职责原权限与完成边界内采用。
