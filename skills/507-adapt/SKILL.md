# 成稿受众与载体适配

作为主要技能，把已经成立的内容变成目标读者能读、看或听的版本，负责本次适配范围和实际交付。用户可从本入口表达目标，Agent也可按需采用并把结果用于原任务。主张、材料和内容足够时直接沿指定版本处理，不重走采访或规划；适配改变受众入口、表达、信息安排、容量与呈现，保留作者判断与事实依据。

共有依赖从[共有资源合同](../../lib/README.md)开始：首次读取参考前，用 `skill_document=$(realpath <本文件路径>) && test -f "$skill_document" && cat "$(dirname "$skill_document")/../../lib/README.md"` 打开合同，参数取当前实际读取的 SKILL.md 路径；其余引用统一按合同解析，已完整读取且未变化的合同直接复用。 持有多阶段原任务时，局部动作完成后按[阶段返回](../../lib/README.md#阶段返回)核对指定交接并继续。

## 与成文和材料工作的分工

| 当前需要 | 采用方式 |
| --- | --- |
| 成熟内容换受众、场景或载体 | 本技能直接完成；为让目标读者理解而大幅改写措辞仍属适配，不按改字数量分工 |
| 重新决定主张、论证或作者叙事，或只润色当前稿件的局部文字 | 由create承接成文与修订；仅一部分需要重新判断时只处理该部分，结果返回原任务 |
| 材料混杂，身份、来源、去重或支持范围值得独立整理 | 按需采用material；普通查一条参考可直接完成，不把材料整理变成必经步骤 |

已有目标、设计和用户修订继续有效。局部适配只改约定范围；采用相邻能力不重新确认同一请求，也不结束尚未完成的原交付。

## 输入、权限与产物

承接成熟稿、指定版本与手改、目标受众、载体、保留要求和修改授权。按[作品合同](../../lib/methods/writing/artifact-contract.md)确定当前内容版本、保护项及派生位置，不回写唯一主稿除非本次授权覆盖。只读建议仍只交建议；有制作请求时完成目标环境中可用的内容和呈现实物。

产物是保义派生稿或内容包，以及实际请求且工具可实现的目标文件、来源映射和检查结果。文章、可见页面、口播与备注各保留必要信息；摘要须有明确提炼请求，不因“图卡”默认删正文。素材许可、账号登录、消息发送、付费生成、安装、提交与发布仍按原授权，不由适配取得。

## 受众入口与载体容量

成熟作品要改变阅读或听觉方式时使用。先从读者已有知识、当前困境、使用场景与需要采取的动作判断理解缺口，不把换平台等同于增长或重新写主张。

结合多份旧稿或突出某项能力时，先对照本次用途、已确认受众与原稿内容，区分沿用的整体范围、需要加强的部分及明确删除项。“以某稿为基础”不等于只保留该稿的主题；调整篇幅和顺序不能默默删去仍服务当前受众的内容。只有用户要求摘要、收窄或既有授权覆盖该取舍时才缩减，并能说明保留与删减的依据。

| 目标 | 内容安排 | 必须保留的边界 |
| --- | --- | --- |
| 文章与平台文字 | 调整入口、层级、长度与相关性；复用原稿判断与材料 | 来源、关键论据、条件与作者声音；改标题不能新增成绩或承诺 |
| 图卡式阅读 | 默认按完整内容与顺序分配页面；明确提炼时才选摘要 | 全文模式不丢可见正文；摘要说明重要未入选内容去向；HTML 不是已导出图片 |
| 幻灯片 | 每页完成认知任务；观众文字、讲者备注与会说出口的稿件分工 | 页面标题保留含义；必要素材真实存在；逐页稿不是已生成 PPTX |
| 阅读网站 | 围绕寻找、阅读、比较、来源与返回安排内容 | 展开或点击不执行源流程；状态与来源不因选中而变成完成 |
| 口播与旁白 | 给耳朵重排节奏，明确段任务、发音与必要画面证据 | 操作必要数字、条件与限制不丢；估时不是实际音频时长；内容包不是配音或成片 |

需要压缩成稿、减少防御性表达或把内部材料变成受众正文时，按[作品合同的受众安排](../../lib/methods/writing/artifact-contract.md#根据受众和容量安排内容)逐项决定保留、改写、移位或删减，保留支撑主张的依据及影响理解或执行的条件。交给修复者的问题清单突出待处理事项、复现依据和复验要求，完整通过记录留在测试依据中。

容量与材料矛盾时，先在目标载体调整结构；还需删关键论据、换主张或扩大承诺才能满足目标时，指出实际取舍与影响，回交作者主线。已有明确修订授权继续有效，不要求再过一次形式审批。

## 适配并验证

1. 按上节核对目标读者要理解、判断或执行什么。已有条件足够时自行安排入口、层级、分页与节奏，不重开总规划。归属、引语或材料支持可能受压缩影响时读[作者与来源](../../lib/methods/writing/author-and-source.md)。
2. 完成目标阅读关系，逐项对应原稿。保留条件、否定、责任、数字对象、时序、来源与未知；必要限制留在对应主张或动作旁。内容超容量时拆页、调整安排或在原授权内缩小范围，不缩字、隐藏正文或用多处摘要代替完整交付。
3. 目标含视觉方向或阅读界面时采用[设计提示](../../lib/methods/design/guides/artifact-prompts.md)，从真实内容与阅读任务选择，不固定模板、候选数量或外站参数。需要用户审美取舍时提供具体候选与理由；机械检查不能替代人的接受。
4. 先按材料辨认时间先后、过程、同条件比较、版面或状态关系。修改已有页面时优先复用项目组件，在原入口核对结果。新建独立离线 HTML 时按[呈现合同](../../lib/methods/design/artifact-rendering.md)，默认用[共有图解组件](../../lib/components/visual/visual-components.md)和[呈现脚本](../../lib/components/visual/scripts/render-artifact.mjs)表达这些关系。普通文字页用正文和列表。必须打开当前 HTML，沿时间、流程、比较或数量联动实际核对理解路径，以及密页、来源、备注和导航。
5. 图片、可编辑 PPTX、音频或视频先按[真实载体适配](../../lib/components/tools/export/media-adapters.md)读齐所选工具的当前合同，确认可用依赖、素材与授权，再在新位置制作并检查目标文件。HTML 预览不能证明 PNG、PPTX 或视频已经生成。目标依赖缺失时交付可用派生内容与最小依赖，标明载体未完成，继续不依赖它的工作。

适配后的中文书面或口播可运行[书面检查器](../../lib/components/tools/checks/check_prose.py)或[口播检查器](../../lib/components/tools/checks/check_spoken.py)，适用边界见[检查器说明](../../lib/components/tools/checks/text-checks.md)。提醒按语境复核，不自动改稿，也不作为事实或作者接受裁决。

若改变读者入口必须新增事实、改因果、换作者主张或删除核心论据，适配已不足以满足目标。保留有效派生版本，带具体问题返回作者主线或成文工作；已有该项授权时直接继续，不要求重新批准整段流程。

成熟内容需要状态图、时序图、关系图或同条件比较以帮助目标读者理解时，可采用 `507-visualize`；图表作为同版派生表达，保留原稿含义与来源，适配仍负责最终载体。简单文字或表格直接完成。

## 完成与接力

- **完成**：当前请求的受众、容量与阅读关系已经落实，关键含义、归属和来源保持；实际目标文件可打开并完成相称内容和呈现检查，降级与未覆盖明确。只请求适配内容时内容包即终点。
- **返回**：交付派生内容、当前版本与真实载体结果；父目标有已授权后续则继续。目标实物缺失保持未完成，不把准备包称成成品；发布仅在另有具体授权时进行。
- **恢复**：材料、工具、素材许可或验证不足时保留可用旧版与失败信号，交付已成立部分及阻塞动作。没有兄弟技能仍按相同责任边界直接处理，不以安装为前提。

本次出现制作比较站或关系阅读工具时，读[对象关系、比较与观察](../../lib/methods/design/visual-understanding.md)并在本职责原权限与完成边界内采用。

用户点名呈现参考、需要将既有设计延续到新载体，或呈现方向有实质缺口时，按[视觉方向与真实反馈](../../lib/methods/design/visual-direction.md)提取应保留的呈现选择，并用目标实物对照核验。确有会改变做法的取舍时再比较候选，普通局部修改直接继续。

成熟材料需变成产品界面卡片、静态展示或模拟操作短动画时，可采用次要能力 `507-demo`。需要自行接入场景时直接使用共有库的 `visual/`，先读[共有运行与接入](../../lib/components/visual/visual-runtime.md)核依赖与许可，不读取兄弟包或另维护一套 kit。保留当前事实与主张，取得可编辑场景、目标实物及检查结果后继续原载体交付。真实功能、软件操作录制及完整成片沿原能力处理。

中断续办、换会话、上下文压缩或转交时，按原授权读[续办方法](../../lib/methods/collaboration/continuation.md)。普通结束跳过。

本次出现制作可操作载体，范围止于呈现而不修改正式业务时，读[操作、状态与实际呈现](../../lib/methods/engineering/interaction.md)并在本职责原权限与完成边界内采用。

本次出现只借呈现结构，不改成熟稿主张与事实时，读[参考视听证据与原创借鉴](../../lib/methods/design/media-study.md)并在本职责原权限与完成边界内采用。

本次出现目标包含真实音频或视频，沿成熟制作工具核实物时，读[媒体版本、时间与验收](../../lib/methods/design/media-production.md)并在本职责原权限与完成边界内采用。

需要实物身份时按[文件回执](../../lib/components/tools/export/artifact-receipt.md)使用[组件](../../lib/components/tools/export/artifact_receipt.py)。文件回执不裁决渲染、语义、许可或接受。

中文密页、图表或视觉关系需要展开时，读[视觉语义与中文呈现](../../lib/methods/design/guides/target-design.md)，保护实际内容关系与当前目标文件。

明确传播目标或标题优化请求时，读[标题与正文兑现](../../lib/methods/writing/title-promises.md)；普通文档不因载体名称启动增长任务。

持续适配按[工作记录](../../lib/methods/collaboration/work-records.md)保留主稿、派生稿、保护项、实际目标文件与检查状态。改动已约定指纹或回执的交付文件后，重算并逐项校验清单；模拟确认只解除对应等待，实机或现场项保持延期。多轮修改涉及须同步的多份交付，或有待确认、延期事项需要接续时，采用 `507-work` 的交付核对做法，在已有记录里维护约定并按阶段检查。单处修改遵守本轮范围，暂停即停。适配仍负责从受众入口走完各载体，核对讲述、实际操作和画面是否对应，再交回整体结果。
