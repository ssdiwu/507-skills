# 作者与作品判断

在共创新想法，或作者主线、材料负载、来源归属或声音仍会改变作品时按需采用。已有清楚稿件和局部目标直接处理。

## 用例子推敲新想法

共创中遇到还在成形的判断，先说清对它的理解，用现有材料中的正例说明它何时成立，再用反例找出边界。新例子能改变判断或澄清条件时才补充。判断已清楚就进入成文。假设情境标明是假设；需要真实案例时按入口的外部取证方法核实。

带着例子指出哪处能保留、哪里值得继续聊。Agent 可顺着作者的联想提出下一问或补一个可能的方向，保留其建议身份。作者的判断已经清楚时，直接进入请求的成文或修改。正文只采用能帮助读者理解或支撑作者判断的例子。

## 主线与材料选择

先判断受众要理解、感受或做什么，中心判断是否由材料支撑。观点作品的真实争论对象可以是命题、标准或结构；教程、事实报告和资料整理无需制造敌对立场。

作者位置或材料支持范围未成立时采用[作者与来源](../../../lib/methods/writing/author-and-source.md)，获得可消费材料后继续判断主线。把每项独立材料放到作品推进中，检查删去它会使哪个关键判断失去依据；不是把材料按原始顺序堆成正文。

有真实竞争主线时比较它们的材料组合、反例、边界、受众承诺和作者愿意承担的判断；已确认主线不重开选择。材料只支持一条成立路径时直接继续，仍有作者实质取舍时回交最小问题。Agent 的结构建议以建议身份使用，不能由建卡、落盘或草稿状态自动变成作者定案。

材料能承载的作品范围与目标篇幅冲突时，说明哪步缺依据，选择缩小或补料。需要的反例与竞争解释参与校准主张，已确认排除项不换名重新进入作品。

## 声音与修订责任

从同一作者可读作品、原话和明确纠正中辨认当前需要的稳定选择：冲突从哪里起、判断到什么深度、证据怎样出现、责任主体如何落在动作、句子如何形成力度。样本不足时保留已有声音与不确定，不制造作者模型，也不把聊天口癖当作品风格。

作者希望校准口吻时，从同类成稿和明确手改中选一个会影响阅读的写法，给短段让作者选择或直接动笔。对照稿尽量只改变这一个写法。将反馈用到下一段，记录它在怎样的段落里成立。一次反馈先用于当下的稿件，用未参与校准的同类素材试写，再判断是否值得作为作者偏好复用。

整体创作由 Agent 完成结构、必要认知台阶和首稿，不让用户承担常规补齐劳动。用户反馈改变局部事实时修对应句及依赖；改变因果或主线时检查全文受影响部分；可迁移声音变化用于当前同类表达。用户明确的新判断直接承接，不重复请求内容确认。

局部表达目标直接修订，不重建主线。指定稿、含义保护与派生版本采用[作品与载体合同](../../../lib/methods/writing/artifact-contract.md)；主张或核心因果确已改变时，由本任务判断受影响的整件作品，避免把新判断塞进尚按旧关系运行的正文。

## 受众承诺与作品出口

标题、主文、结论与受众拿走的结果兑现同一承诺。说明读者现在为什么需要这件作品，但读者入口不是事实证据，不为代入感制造经历或反馈。

图像、页面或视频在主线中的作用须具体：举证、展示结果、解释关系或提供观察。先判断当前材料与受众目标需要什么，再采用相应做法；不让载体形式反过来补造内容。出口依[作品与载体合同](../../../lib/methods/writing/artifact-contract.md)核对当前版本、实际呈现与返回，作者接受与发布各自成立。

## 只交候选时的结果

仅要求选题或作品候选、主线确有真实竞争时，每个可判断候选包含题目、中心判断、受众为何需要、独立材料组合、论证推进、暂不采用的解释与材料能承载的作品上限，并说明推荐与代价。只要候选池则止于候选，不顺带写全文；已有选定主线时跳过候选比较，直接沿原授权完成作品。候选中的作者推断保持待确认身份，不因推荐或推进许可变成作者定案。
