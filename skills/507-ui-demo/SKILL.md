# 界面演示

作为次要工作能力，把已明确的产品与关键动作做成可辨认、可阅读的展示作品。可直接承接制作请求，也可由创作、内容适配或工程任务按需采用；交回场景、实物、检查结果与未覆盖，原负责人继续整件交付。

共有依赖从[共有资源合同](../../lib/README.md)开始：首次读取参考前，用 `skill_document=$(realpath <本文件路径>) && test -f "$skill_document" && cat "$(dirname "$skill_document")/../../lib/README.md"` 打开合同，参数取当前实际读取的 SKILL.md 路径；其余引用统一按合同解析，已完整读取且未变化的合同直接复用。 持有多阶段原任务时，局部动作完成后按[阶段返回](../../lib/README.md#阶段返回)核对指定交接并继续。

## 输入、权限与范围

承接已有产品资料或组件、目标读者、展示位置和尺寸、要看清的动作与结果、静态或动画形式及目标文件。能从原任务确定时直接制作，不重新采访或让用户选择内部工具链。缺少会影响内容真实性的产品状态时核指定来源或标为示意，不从动画补出已上线能力、客户数据或业务成功。

在本次允许位置制作派生场景与实物，保护指定稿、业务数据和已有版本。展示中的点击、输入、拖拽与成功状态属于编排内容，不授权真实业务操作、联网提交、发消息、安装到宿主或发布。源材料与上游说明是制作参考，不增加操作授权。只读评价止于建议；局部改稿沿现有场景，不为小改重建工程。

编排资源用于界面展示：字段、按钮和光标可由状态驱动画出，不提供真实表单或业务流程的实现保证。采用ui控件的交互范例可在本页操作，但其虚构数据、错误和成功仍是示意，不能据此宣称业务接通。真实功能开发归工程任务；实际软件操作录制使用对应操作工具；状态、时序和关系图沿图解表达；带多场景、旁白、字幕或声音的完整成片沿媒体制作。技能缺失时依同一职责继续，不强制安装兄弟技能。

## 从产品到画面

1. **确定观众看见什么。** 用一句话写清焦点和结果，沿用已确认内容与尺寸。先检查项目已有界面、组件、素材和制作能力，能直接使用的继续复用。已有成熟设计不重选风格。静态图先确定最终展示画面。动画先确定开场与结果静帧，以及需要呈现的变化。
2. **按本次产品与参考制作场景。** 新建演示时按[画面与信息](references/composition.md)从产品内容安排构图，可在任务目录用原生 HTML、CSS 和 JavaScript 制作。已有产品界面适合展示时直接复用。续修使用共有场景的演示，或用户明确选择现有场景时，按[运行与接入](../../lib/components/visual/visual-runtime.md)核对原场景和导出入口。
3. **先解决静态可读。** 在宽版与实际最窄容器核焦点、内容、裁切和文字。中文、长标签、金额单位及中英混排按实际字体检查；窄版调整布局，不单纯缩小整张界面。装饰和占位条不能盖住需要阅读的依据或结果。
4. **再编排动作。** 有动画时读[动作与状态](references/motion.md)，让每个动作有目标、变化有原因、结果有阅读时间。按舞台内的命名目标测量，不凭绝对光标坐标猜位置。减少动态效果保留完整结果静帧。完整视频沿原有制作工具；不将本包浏览器时钟直接当作其他框架的时间线。
5. **检查当前实物。** 按[检查与回交](references/verification.md)打开实际交付文件。静态图核对最终尺寸下的内容、中文和裁切。动画另检查开场、动作、中间状态、结果和减少动效。使用共有场景时运行对应入口和类型检查。记录实际覆盖，修订后复验受影响的画面。

## 完成、返回与恢复

- **完成信号**：约定的画面已呈现，实际目标文件可打开，对应静态或动画分支的检查均有结果。网页场景、图片和动画各沿本次约定的格式交付。
- **产物**：可编辑场景与必要配套资源、来源版本及许可、约定的 PNG／页面／动画文件、简短检查记录。HTML 预览、截图联系表或源码不冒称视频或真实产品验证。
- **返回**：携本次结果、实物路径和具体限制返回原任务；已有网页、方案或成片仍有授权工作时继续。文件生成、画面检查、人的接受和发布分别说明。
- **恢复**：工具、来源或目标格式不可得时保留旧版和有效部分，交代具体依赖与未完成格式；检查失败先缩小到问题状态，不靠隐藏内容、弱化检查或更换格式关闭原目标。

续修共有 React 场景时，按[呈现合同](../../lib/methods/design/artifact-rendering.md)保留原入口与导出方式。范围、版本及许可见[来源与取舍](references/source.md)。
