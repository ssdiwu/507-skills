# 507-rednote 产品需求

状态：已实现并完成本地验证，作为当前产品与验收基准。动态媒体设备识别与外部发布仍按各自独立门禁验收。

本需求延续[小红书图文区分连续文章与视觉摘要](../doc/决策档案/0015-小红书图文区分连续文章与视觉摘要.md)，并落实[小红书图文采用三轴视觉与单一 DOM 分页运行时](../doc/决策档案/0019-小红书图文采用三轴视觉与单一DOM分页运行时.md)。

## Problem Statement

现有 `507-rednote` 要求 Agent 先把内容拆成物理 `pages` 和 `blocks`，再交给脚本渲染。分页不是最终 DOM 的编译结果，动态预览、文件状态和导出也没有形成一个持续可编辑的工作台。参考实现 RedNoteImage 提供了三栏编辑、实时预览、主题选择和多格式导出的产品形状，但只保存在 `localStorage`，使用简化测量 DOM 与 HTML 字符串分页，最终页面可能裁掉末行或组件。

视觉状态同样被压扁为主题、配色和逐页布局字段，无法表达“语义组件 × 设计语言 × 视觉呈现”的稳定关系。文章模式还使用 3:4 封面与 3:5 正文混合画布，与实际认可的 1500×2000 成品不一致。

## Solution

`507-rednote` 提供一个可由 Skill 直接启动的本地动态工作台：左侧编辑 `content.md`，中间以响应式网格连续预览全部 3:4 页面，右侧调整三轴视觉计划和导出设置。内容、视觉计划和真实分页结果自动保存到作品目录；导出是显式动作。

默认 `article` 模式把成熟主稿编辑为连续平台稿，物理页面只是最终 DOM 的阅读切片。明确要求提炼时才进入 `summary` 模式。两种模式共用同一语义组件、三轴视觉 Resolver 和浏览器渲染器。

## User Stories

1. 作为内容作者，我调用 Skill 后希望直接得到已填入当前正文、可以打开并继续编辑的网站。
2. 作为手机读者，我希望封面和正文均为 1500×2000 的 3:4 页面，所有文字与组件无需放大且没有裁切。
3. 作为内容作者，我希望上传一张封面图片，也能在正文光标位置上传并插入 Markdown 图片，然后立即看到真实分页结果。
4. 作为内容作者，我希望标题、段落、列表、代码、表格、流程图和图片按原文位置连续排版，装不下时自动续到下一页。
5. 作为内容作者，我希望先从丰富的完整外观预设中直接选择，需要时再进入高级设置切换基础设计语言或视觉呈现；重新分页不改变文字、顺序与来源映射。
6. 作为内容作者，我希望只使用许可明确且随 runtime 固定的字体，并能显式切换字体与字符占用宽度；相同 typography 状态不能因切换 preset 而暗中回退另一套系统字体。
7. 作为交付接收者，我希望动态预览、HTML、PNG、JPG 与 PDF 来自同一份 DOM、分页状态和视觉计划。

## Confirmed Constraints

### 1. 内容模式

- `article` 是默认模式；标题、小节、正文、列表、代码、表格、流程图、图片和图注全部进入图片，顺序一致，未入选内容必须为空。
- `summary` 只有在用户明确要求“视觉摘要 / 一页一个观点 / 提炼 / 精华版”时启用；每页观点和证据映射回来源，未入选重要内容记录去向。
- summary 的封面 H1 后以强制分页指令分隔观点段；每段必须且只能有一个标题并完整落在一页，超出时失败而不缩字。
- `raw.md` 是长文主稿，不由网页自动回写；`content.md` 是小红书实际可见的平台稿。
- 普通 `---` 保持 Markdown 水平线语义；`<!-- rednote:page-break -->` 是不显示的强制分页指令。
- Markdown 链接在最终页面显示完整 URL；机械展开由渲染器完成。

### 2. 三轴视觉系统

- 语义组件回答内容是什么，包括封面、标题、段落、列表、引语、代码、表格、流程、关系图、图片、截图和动态媒体。
- 设计语言回答整组作品如何说话；一组作品只使用一个基础设计语言。它是层级、网格、轮廓、间距和色彩行为的底层语法，不是一套完整成品样式，也不暗中替换具体字体。
- 视觉呈现回答某个语义组件如何被看见，并受兼容矩阵约束。
- `preset` 是已验证的完整组合入口，同时固定设计语言、具体配色、组件视觉呈现和 treatment；多套 preset 可以共用一种设计语言，preset 数量不受六类设计语言限制。它不得替代三轴状态或宣称所有组合天然成立。
- `default / inverse / section-emphasis / dense` 是受控 treatment，不是第四轴。
- 页码、日期、头像等 page chrome 属于可选载体装饰，不进入正文覆盖计算。
- 文章模式的视觉呈现绑定语义组件，不绑定物理页面；不能因分页把连续文章改造成课件。

### 2.1 字体与阅读密度

- runtime 原样内嵌 Adobe Source Han Sans CN Variable 2.005R 与 Source Han Serif CN Variable 2.003R 官方 WOFF2；两者均为 SIL OFL 1.1，商业使用、嵌入与随软件再分发的边界进入第三方 notice。
- `fontFamily` 是独立 typography 状态，默认 `source-han-sans`，可显式切换 `source-han-serif`；切换 preset 不改字体。
- 正文、引语和列表共同消费 `bodySize` 与 `lineHeight`，不能出现控件数值相同但组件仍使用隐藏固定值的情况。
- `characterWidth` 为 0.94～1.08，通过 -0.06em～0.08em `letter-spacing` 改变字符占用横向空间并进入真实 DOM 分页；不得使用只改视觉、不改布局测量的横向 transform。
- 本地字体、许可证或固定哈希缺失时停止启动或渲染，不静默回退到苹方、宋体或其它机器相关字体。

### 3. 画布与分页

- 小红书封面、文章正文和摘要图卡统一使用 1500×2000 的 3:4 画布。
- 分页由最终字体、素材、页边距、组件呈现和 page chrome 已生效的真实 PageShell DOM 测量产生。
- 预览宽度只改变一行显示一页、两页或多页的缩放与网格，不改变真实分页。
- 正文、标题和引语不通过缩字解决溢出；列表优先按条目续页；代码按完整代码行续页；表格有限压缩后按行续页并重复表头。
- 标题可以出现在页中，但不得孤立在页尾；图片、截图和流程图优先完整包含，不能静默裁切。
- 强制分页、自然分页和组件续页必须在分页产物中可区分。

### 4. 文件状态

- `content.md` 是可见平台文案的唯一当前来源。
- 工作台上传的封面与正文图片保存在作品 `assets/`；正文上传会在光标处向 `content.md` 插入标准 Markdown 图片，封面上传只更新视觉计划的素材路径。
- `visual-plan.json` 保存设计语言、组件视觉呈现、treatment、封面、`fontFamily`、字号、行距、字符占用宽度、素材角色和 page chrome。
- `paged-content.json` 是 runtime 自动生成的编译产物，不允许 Agent 或用户手写分页；记录输入哈希、页面可见文字、语义组件片段、来源范围和测量证据。
- `render-manifest.json` 记录 runtime、内容、视觉计划、字体、素材、分页和导出文件的新鲜度。
- 任一输入哈希变化时旧分页立即过期；过期或验证失败的状态不得导出。

### 5. 本地工作台

- 工作台采用内容编辑、响应式成品预览、视觉与导出设置三栏结构；窄屏可以折叠侧栏。
- 主界面展示可直接选择的完整 preset；六类基础设计语言与逐组件视觉呈现收在高级设置，不以底层枚举冒充视觉方向数量。手动改变第三轴后进入可保存的自定义组合。
- 工作台独立展示字体、正文字号、行距、字符占用宽度和页面留白；字体选项必须显示许可类型，任何变化自动重新分页并保存。
- 网页编辑自动保存文件，不设置人工“保存”门槛；失败时保留用户文字并显示明确错误。
- 本地服务只绑定 loopback，作品目录是唯一可写根目录，文件使用候选写入与原子替换。
- 工作台不会把正文、图片、视频、头像或凭据上传到外部服务，不依赖运行时远程 CDN；界面中的“上传”仅指从本机选择并复制到当前作品目录。

### 6. 同源导出

- 动态预览和 CLI 直出使用同一前端 bundle、三轴 Resolver、PageShell 和分页器。
- HTML 是当前状态的可打开快照；PNG、JPG 和 PDF 从同一页面 DOM 导出。
- Live Photo 继续以静态页面首帧为基准，通过 FFmpeg 与 makelive 后处理；公众号封面对继续独立构图。
- 导出完成后，分页规格、清单、实际文件和联系表页数必须一致，目录中不得残留旧页。

## Acceptance Criteria

- [ ] 调用 Skill 可以直接打开本地工作台，并从作品目录读取或创建 `content.md` 与 `visual-plan.json`。
- [ ] 本地图片可以上传为封面；正文图片上传后以标准 Markdown 写入当前光标位置，刷新后两者仍能从作品 `assets/` 恢复。
- [ ] 主界面提供多于六套完整 preset；基础设计语言和逐组件视觉呈现位于高级设置，选择 preset 会同步完整配色与组件呈现，手动调整后转为自定义组合。
- [ ] 思源黑体与思源宋体均从固定本地 WOFF2 真实加载；字体文件与许可证 SHA-256 进入 runtime/fontSet 新鲜度，缺失时明确失败。
- [ ] 字体、字号、行距和字符占用宽度可分别调整并刷新恢复；引语和列表不再绕过正文排版状态。
- [ ] 保持相同 typography 状态切换不同 preset 时，具体字体及其度量不变；只有组件内宽或视觉呈现确实变化时才允许重排。
- [ ] 桌面宽度下中间区域默认可并排显示两页；更宽或更窄时响应式增减列数，真实分页不变。
- [ ] 1500×2000 封面和正文来自同一个 runtime，预览与导出页面内容一致。
- [ ] 长段落、页中标题、列表、代码、表格、完整 URL、强制分页、图片和流程图均有真实内容 fixture 且无裁切。
- [ ] 每个可见 fragment 都回链组件来源范围，分段组件的 `visibleRange` 连续覆盖组件可见文字；页面 `overflow` 全为 false。
- [ ] 切换三轴视觉组合会使旧分页过期并重新编译，不改变可见文字和顺序。
- [ ] 刷新工作台后自动恢复文件状态；写入或渲染失败不会丢失平台稿。
- [ ] PNG、JPG、PDF、HTML、联系表和 manifest 的页数、哈希与尺寸一致。
- [ ] 文章模式保持连续阅读；摘要模式仍能生成来源可追溯的一页一个观点图卡。
- [ ] 静态图片之外的 Live Photo 与公众号封面对既有边界不回归。

## Out of Scope

- 账号登录、小红书或公众号上传、发布与运营。
- 从长视频自动选段、剪辑或生成叙事序列。
- 在浏览器内调用外部生成模型；封面与配图由 Skill 在已有授权范围内生成或选择。
- 允许用户上传许可证未知的任意字体；新增字体必须先进入受控注册表并补齐商业使用、嵌入、再分发与修改边界。
- 支持任意规模 Mermaid 语法；首版只承诺受控、可验证的流程与关系图子集。
- 保留永久双轨分页器；旧规格只允许有期限的一次性迁移。

## Further Notes

RedNoteImage 作为产品形状和失败证据，不作为可直接复制的代码、依赖或资产来源。运行时依赖必须固定版本、离线可用并进入来源与许可证记录。现有 1440×2400 正文、手写 `pages/blocks` 和平铺视觉字段由本需求取代。
