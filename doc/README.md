## 文档层级与归属

| 层级 | 内容 | 存放位置 |
| --- | --- | --- |
| 现行依据 | 术语给出对象的含义，技能合同规定单项任务的动作，规格规定跨技能行为及验收。修改要求时更新对应原文。 | 根目录、`skills/`、`spec/` |
| 设计理由 | 架构说明解释各对象怎样协作。已采纳的重要取舍记录背景、决定和影响。 | [架构与运行资料索引](10-架构与运行/README.md) · [决策档案](决策档案/README.md) |

| 实施与验证 | 方案记录拟达成的结果，试用和审计记录具体版本的观察。判断当前行为时，需对照现行规格和同版证据。 | `30-独立审计/`、`40-版本实施方案/`、[运行记录](10-架构与运行/README.md) |

## 从实际问题找依据

**“工作推进为什么漏了一项？”** 先读[工作技能的完成与接续条件](../skills/507-track/SKILL.md)，再用实际会话核对遗漏发生在识别事项、执行还是回到原目标的环节。历史试用可提供复现案例。

**“共有库为什么采用这一层级？”** 当前资源从[库入口](../lib/README.md)查找，选择这一结构的理由见[架构决策 0025](决策档案/0025-按用途组织共有资源库.md)。
