其余任务从[全部技能](../skills/README.md)找执行合同。需要追溯其他取舍时，按[决策目录](决策档案/README.md)的标题和替代说明找原文。具体版本的执行与验证范围见[公开进度](../PROGRESS.md)。

**“工作推进为什么漏了一项？”** 先读[工作技能的完成与接续条件](../skills/507-work/SKILL.md)，再用实际会话核对遗漏发生在识别事项、执行还是回到原目标的环节。历史试用可提供复现案例。

**“共有库为什么采用这一层级？”** 当前资源从[库入口](../lib/README.md)查找，选择这一结构的理由见[架构决策 0025](决策档案/0025-按用途组织共有资源库.md)。
