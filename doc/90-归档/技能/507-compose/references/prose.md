# 书面成文与局部修订

现有目标与材料已经足够写文章、文案或改稿时使用。不强制观点文结构、创意卡、固定篇幅或项目资料库。

## 指定范围润色

读取完整约定范围及必要上下文，先辨认句子在提供事实、判断、条件、过渡还是有意节奏，再修语法、词序、照应和歧义。保留准确可读的原句，允许为可读性分句分段，不能顺手改结论、删论据或补原稿未有的因果。

含义风险超出授权时保留受影响原句，另给原句、候选、理由与风险；普通语言修改自行完成。无法读取的部分保留位置并说明未覆盖，不猜写剩余稿。局部润色不套整稿压缩、重新采访、平台转换或固定段首格式。

## 完整成文与结构重写

复用目的、读者入口、作者主张、必要材料与范围，选择能让读者从真实对象走到判断的顺序。事实说明可以直接陈述；教程按操作依赖推进；叙事按真实行动、结果与变化组织；只有观点型材料存在真实分歧时才处理争论对象，不为每篇文章制造敌人。

内部核对每个关键推进由哪份事实、亲历、反例或必要推理承载。材料只够一例就讲透一例；抽象意义和重复解释不填目标字数。读者入口建立相关性，不能作为事实证据。标题承诺方法、资源或成果时，正文或真实可取得附件须兑现；仅在本次有传播目标或明确改标题请求时调整吸引力，不为视觉排版自动重拟标题。

作者声音按真实材料中的冲突起点、判断深度、证据顺序、主体动作与句子力度形成。保留有意反问、重复、括号与不齐整呼吸；事实处克制、判断处有力度可以并存，不统一抛光成报告语气，也不加口癖表演个人性。

完整稿形成后检查段落任务、新增信息、支撑依据和前后接力，删除没有信息、判断或过渡作用的冗余。中文检查器只提示可复核形状；准确术语、真实引语、必要否定和有功能修辞保留。再逐句核对归属、数字对象、时序、因果、完成状态与边界，完整通读。结尾只落实本文已承载的判断或行动，不靠新论点完成收束。

交付沿项目或用户指定格式；没有该约定时采用适合当前文本的普通格式，不套特定作者的段首缩进、禁词表或发布习惯。主稿可用与作者已经接受分别报告。
