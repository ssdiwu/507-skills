# 当前工作、执行与过程记录

在跨会话接续、独立工作委托或实质状态变化时采用。本参考把共有权威/返回和验收方法用于工作记录，不另建日志Skill或业务总台账。

先定位原任务系统／工单、已有PROGRESS和相关过程文档。业务事项、执行者状态、自动检查、独立验收、接受和发布分别成立；执行者交回不表示原目标完成。旧过程与自报作为有版本的依据，不能覆盖较新的明确用户修订或独立结果。

当前快照只保留目标、影响下一步的结果与证据入口、未完成与依赖、下一责任人／动作。关键过程写入已有阶段记录或工单评论；材料已存在则回链，不重抄每条工具调用或完整聊天，不为一次局部任务新建WORK_LOG。缺少持久消费者时在结果中交回摘要即可。

需要持久记录时只补接续所需的事项与范围、执行者、事件时间／基线版本、实际动作与结果、证据入口、阻塞和下一责任人；字段按任务删减，不要求每次填满。试验或拟议状态不能写成真实平台已更新。

目标负责人或指定整合者维护共享当前快照；同一工作树只有一个写入者。并行修改在独立工作树进行，各自交回产物与版本、结果与未覆盖。独立审查使用被冻结的候选或记录明确基线；代码/文档的写入权切换明确交回，不因某agent停止或限流自动夺取。

接手者先核当前快照和相关过程，再按未解决事项读取必要的规格/产物/证据。没有原对话时不靠猜测补权限；明确不受阻动作继续，受阻范围与最小依赖带回当前目标。handoff引用正式资料并补尚未持久化的运行信息，不成为第二份长期权威。
