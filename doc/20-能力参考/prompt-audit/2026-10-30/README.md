## 行为观察与发现处理

独立验证者先保存8项输入和单独预期，由另一执行者读取隔离的完整技能包与样本：只读检查真实失效路径、排除生成输出和占位路径误报、区分不同作用域、核维护源与生成／历史身份、保留有效数据保护、区分宿主与未知模型、零发现及局部导航修改。首轮仅获准的导航样本发生预期变化，所有技能包保持原指纹。审计结论是样本文件的静态判断，未运行真实宿主加载或模型效果对照。

首轮将普通项目指令的跨宿主审计误选为 `skill-design`，预期为 setup。因受审对象不是技能包，已把该入口描述收窄为“技能包中的”审计，并明确项目工作指令核对沿原职责。没有改变方法正文或放宽预期。

修订后新执行者先保存入口选择，再读取正文与方法：技能包审计选择 skill-design，局部导航选择 setup；跨宿主指令审计选择 review，与原单一预设 setup 仍不一致。独立审查核对现有合同后确认 review 可以由未参与样本实施的执行者直接只读审查指定指令，用户不必显式说出“独立”，因此该选择属于合法重叠。保留原预设和偏差，不将精确路由结果改写为全通过，也不为强制唯一入口继续收窄 review。

首轮报告如实记录了提前批量读取正文及工具输出截断；后续补读与最终样本／包指纹可核，但没有将执行者的读取自报当成每次完整读取的独立证明。定向复测的两阶段调度和选择记录支持先保存入口选择、再读取正文，但第一阶段没有原始读取回执；第二阶段保留读取及修改命令输出。三项复测的任务行为和权限均符合预期，指纹确认仅获准的导航样本变化、三个技能包未变；与首轮分开报告。

独立审查还发现方法导航中新行与表格之间有多余空行；已移除并复查。该修订只改变表格呈现。另按独立审查补充 Claude Code 对 `AGENTS.md` 的版本与设置条件，以及不读取 `AGENTS.override.md` 的差异；一手出处已核，未改变共享方法或调度。
