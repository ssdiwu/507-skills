# 两项高置信审计发现的修订

日期：2026-10-30。本次只处理实际只读审计中确认的两项低风险表述问题，保留之前的方法接入记录、历史审计、原补丁、归档和试用证据。HyperFrames 待核项不在修订范围；本轮不提交或推送。

## 发现与修订依据

1. [行为不变修改方法](../../../../lib/methods/behavior-preserving-change.md)原开头将 component 与 how、do、clean 并列为工作角色，和现行[组件职责](../../../../spec/技能分层与共有资源.md#产品界面组件查找与抽取)、退役声明不一致。本次只将已有组件抽取迁移职责归回 do，保留授权、已有重复使用位置、行为保全和 review 只读等条件。唯一维护源修订后再生成 how、do、clean 三份副本，不恢复旧入口或交接。
2. [PROGRESS](../../../../PROGRESS.md)原“现行目录”段把“本次仅迁移布局、不改变技能职责”写成未限定时点的现行总述。本次明确其属于此前布局迁移阶段；规格中19包、282文件的候选试用段也改标为此前记录，保留原数字、实际结果、未覆盖、数据保全和当前状态回链，不将旧推送结果归到本次未提交增量。

两项均属于现行文本与已确认职责／阶段的一致性修订，尚未观察到相应误调用或误判的发生率；没有以模型升级为由删规则。Claude Code 与 Codex 均适用该文本修订，不依赖某个模型的默认行为。

## 验证与独立复核

候选先在隔离位置修改，验证维护源与三副本、完整包检查、引用和变更范围。核对除开头职责说明外的方法正文不变、历史数字与证据不变，且 HyperFrames 方法及副本保持原指纹。候选同步及包检查通过，仍为20个技能、290个包文件、226份共有副本；变化文件本地链接无缺失，差异空白检查通过。除方法开头外正文逐字一致，受保护的410个历史／媒体方法文件保持原指纹。此次未改脚本或工具行为，不另建测试程序或重跑无关媒体测试。未参与修订的执行者独立核对源与三副本、原正文保全、历史证据和包／链接，限定范围未发现阻塞。两项修复已按核验指纹局部落地；实际宿主自然采用和误读发生率未验证。HyperFrames 待核项在两项修复验证、独立复核后另行只读检查，不因此扩大本次文件修订范围。
