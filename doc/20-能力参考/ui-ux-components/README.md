# UI／UX组件参考

本轮按浏览器书签“04 界面设计与组件”登记21个原网站，并结合已保存灵感笔记提炼16条模式。具体原站与读取边界统一维护在[共有资料来源](../../../lib/design/references.md)，模式唯一维护在[patterns.json](../../../lib/design/patterns.json)，提示模板见[prompts](../../../lib/design/prompts.md)。不在此复制一套模式正文。

提炼区分页面、使用流程、交互模式、控件、风格和实现机制；同名跨框架对象不当同一实现，来源多个版本不重复计赞同。公开文档只保留原网站，不复制私人库正文或具体项目要求。私有站保留原笔记版本、入口取得、组件页和少量实操证据。

本轮原站实操包括AI Elements来源展开、Motion Primitives的Preview/Code切换，以及Bencho Asset swap方向/圆角/视图切换；它们是公开组件演示，未安装、未接真实业务或审全库源码/许可。部分入口只取得壳或导航，另有访问失败；不能说21个网站或全部组件已完成深度实操。

从具体状态、失败、中断、焦点与输入方式提炼的消费者合同是本轮建议；原站的文案、代码入口或视频不能证明它们全部已有相同保障。真正采用时按指定版本、项目环境和实际目标路径验收，复用既有能力优先。
