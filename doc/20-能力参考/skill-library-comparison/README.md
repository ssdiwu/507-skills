## 来源与统计身份

2026-10-11 核对公开目录完整递归树，只计指定范围的主 SKILL.md；模板、参考、规则、自动化和内部维护入口分别排除。当前源基线 30 项；pstack 51、Matt 38、Cursor Team Kit 18、Anis 168、Anthropic 19、Superpowers 15、Corey Marketing 50、Vercel 9。冻结版本不承诺未来仍是最新。

原库与 Anis 采入版是不同版本对象，同源不重复计作独立赞同。Matt 当前比较版本比较早的原子矩阵版本前进 42 个提交、13 份主文改变，数量仍 38；旧条款不能重标为新版。

## 已获得的结构启发

| 来源 | 可用于比较的思路 | 需要保留的差异 |
| --- | --- | --- |
| pstack | 模式选择情境方法、按需专业能力 | 原则叶子仍是 Skill；playbook 是配套资料 |
| Matt／Anis | 用户流程与复用纪律分开，主题分支放参考 | 调用策略与共享归属不同，内部使用不表示宿主隐藏 |
| Anthropic／Vercel | 产物与领域知识可采用不同入口粒度 | 一份规则、参考或文件不机械等于一个原子 |
| Superpowers | 生命周期、方法与元技能组合 | 启动 hook 的强引导与普通按描述选用不同，不能据此证明适合本项目 |
| Marketing | 共享业务背景、规划与具体渠道执行分开 | 读取共用背景不等于每轮重跑总规划 |

## 原子与验证范围

前期研究登记 196 个选定归一原子、587 条证据映射；208 份主文有选定映射，144 份尚未映射，352 份主文件包含版本重复。另完整读取 8 份主文，按当轮粒度登记 192 个主要合同单元，参考内部未展开，不是全库均值或全部细原子的穷尽。

这些数量用来记录研究覆盖，不作为能力排名、未来入口预算或效果证明。新四库的规模和封装结构核对不能升级成已完成原子全量映射。工具化提议的令牌与错误改善未做真实对照；没有核实的原帖或截图归因不作为上游当前实现证据。

原研究资料包含本机路径、附件和制作状态，本阶段不整份复制到公开仓库。这里保存自有摘要与公开链接；未复制上游完整正文，也不对其内容声明本项目许可。以后确需采入原件或代码时，先冻结版本、核对许可并保留 notice 与指纹，按来源边界维护。
