# 产品 UI 能力整合

研究日期：2026-10-08。目标是将已确认需求与视觉方向交付成可操作界面，包含授权范围内的实现、实际渲染和操作验证。用户选择了这一终点；只讨论、只审查或只做样稿的具体任务仍受其各自范围约束。

2026-10-09 的标签页、图标、分享和节点端口参考按当前合同原位迭代，已有覆盖、必要补充、不采用及来源／验证边界见[本轮比较](2026-10-09-参考迭代.md)。

## 职责比较与采用

| 能力 | 输入与触发 | 产物、权限和终点 | 本次采用 |
| --- | --- | --- | --- |
| impeccable | 产品 UI 与品牌前端的构建、评审、打磨请求，项目上下文与设计 brief | 确认设计、实现、浏览器迭代；部分命令只读，产品／品牌混合入口 | 吸收产品任务的熟悉性、共享组件、完整状态和浏览器迭代方法，重写为本仓库 UI 合同 |
| apple-design（独立入口退役） | 容器、手势、可中断过渡、材质与排版问题 | 条件性的设计与实现知识，不是完整业务交付入口 | 方法由 507-ui 的条件参考承接，原件保全；不将平台风格或示例参数变成所有产品要求 |
| 507-ui | 已确认目标下的产品页面、控件、表单和工作台设计／实施／打磨 | 范围内实现、关联项目规则与实际操作证据；只读请求止于结论 | 作为 507 体系唯一产品 UI 主入口；包内保留必要方法，可独立使用 |
| 507-taste | 视觉方向未定，确需用户从真实候选中选择 | 方向与收敛记录，止于视觉选择 | 保留；已有明确方向时不额外采样 |
| 507-prd | 整理已确认产品行为与验收 | 当前规格，不冒充实现或运行结果 | 保留项目要求归属，与 UI 的实现交付接力 |
| 507-fix／test | 已明确故障或测试任务 | 各自修改授权与故障／测试证据 | 保留；不是每次 UI 任务的强制前置 |
| 507-review／inspect | 明确交付审查或主动架构检查 | 独立只读发现与路由 | 保留，UI 自查不能替代独立审查 |
| 507-ppt／rednote／内容与品牌能力 | 对应载体、成熟内容或品牌形象 | 对应内容成品与载体验证 | 保留，本轮不把它们并入产品 UI |

本次新增入口有专门方法与独立终点：承接方向后把操作、业务事实、视觉呈现和验证连接起来。它不只是转发到外部技能，也不将普通后端实现包装为 UI 工作。前轮精简后的 28 项变为 29 项，分组为 common 7／code 11／write 11。

## 吸收与校准

保留产品 UI 的熟悉性、共同视觉语汇、语义实现、真实内容、完整状态、响应式和浏览器迭代。放弃外部默认的 PRODUCT 文件篇幅门槛、无论材料是否充分都重开访谈、每次独立批准 brief、固定图片探索数量与一套适用于所有页面的禁用风格。必要的真实用户取舍继续保留。

研究中的按钮、输入、选择、日期、搜索和提示规则承接到交互方法：状态维度可组合；回执分别表达保存、接收、待批、运行和未知；重要错误持续可处理；有效默认值与草稿保留；旧响应不能覆盖新对象。44px、两秒提示、300ms 防抖、骨架屏延迟、字重／圆角数量和 60／30／10 比例只代表来源示例，不能替代平台条件、项目设计和实际结果。

Apple 知识用于判断菜单与任务容器、来源关系、从当前呈现值继续的可中断过渡、直接操控、材质可读和减少动态效果。现有原生或项目能力足够时继续复用，不自动加入弹簧、玻璃或动画库。

通用判断归 SKILL 与条件参考；项目共用视觉目标归 DESIGN，具体动作、权限、状态和验收归 spec，实际实现与运行结果由组件和正式业务／运行通路承担。验证记录指明版本、环境、动作、结果与未覆盖，不建立第二份状态源。

## 消费者与完成边界

根与代码流导航使用 507-ui 作为产品 UI 主入口，旧产品主方法以来源记录身份保留，不另加一个相同职责的 507 包装入口。初轮整合没有修改已安装源；2026-10-09 按后续清理请求，将 apple-design 的两份已识别原件和一个软链接退出技能发现目录，完整原件与恢复信息另存。容器与连续反馈保留在原参考；尚未展开的手势、速度、弹簧与排版细节由[Apple 交互细节](../../../code/507-ui/references/apple-interaction.md)按需承接。退役及验证见[记录](../../40-版本实施方案/Apple知识归位与入口退役验证.json)。

impeccable 和此前停用的 507 入口不随此项清理改动，新 UI 也不因此自动安装或启用。文件存在不等于自动发现或重复加载；宿主缓存清单刷新与实际调用分别核验。

隔离前向执行、来源核验、元数据／引用检查、独立交付审查与未覆盖范围见[验证记录](../../40-版本实施方案/UI能力整合验证.json)。前向样例不写入产品主工作树，不证明真实后端、审批、执行器、设备或用户视觉接受。
