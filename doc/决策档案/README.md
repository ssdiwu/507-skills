保留会影响当前技能、产品规格或维护方式的取舍。调整默认行为、权限或交付边界时，从对应理由核对原前提。已完成的迁移、命名和被取代的方案通过 Git 查询。

历史决策会保留当时涉及的产品名、路径与迁移入口，用于解释背景和代价；这些内容不构成当前宿主支持名单。当前公开兼容边界以根 [`README.md`](../../README.md) 与 0004 为准。
