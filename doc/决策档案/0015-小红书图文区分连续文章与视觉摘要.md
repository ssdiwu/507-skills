# 小红书图文区分连续文章与视觉摘要

`507-rednote` 将“连续文章图文”与“视觉摘要”作为两种显式内容合同：用户只要求小红书图文时，默认完整保留成熟主稿，把文章连续排版后切成阅读页；只有用户明确要求提炼、一页一个观点或精华版时，才进入视觉摘要。

这一决策取代 0013 的默认视觉摘要合同。实际交付证明，仅把全文文字分配到多张观点卡仍会改变作品形态：逐页标题、布局、页码和品牌元素会把文章变成课件，迫使字号缩小并打断原有叙事。文章模式因此把文章而非物理页面视为内容单位，允许标题位于页中、段落或句子跨页、证据图嵌在原文位置以及尾页自然留白；正文页不声明逐页观点或布局。

代价是文章模式的单页不再保证一眼闭合，视觉变化也少于摘要图卡；收益是作者声音、原文结构和手机阅读连续性得到保留。需要更强信息流表现时，用户仍可显式选择视觉摘要。动态图片槽与公众号封面对的既有职责和停止位置不变。
