# 视觉幻灯片采用三轴组合与分级载体支持

`507-ppt` 的当前视觉系统采用“语义组件 × 设计语言 × 视觉呈现”三轴模型。语义组件由成熟逐页内容决定；一套 deck 使用一个基础设计语言与受控 treatment；视觉呈现按页选择，并由兼容矩阵限制。旧 `swiss / magazine / cobalt / clay / forest / noir` 保留为已验证组合 preset，不再充当底层样式枚举。

## 为什么

组件、设计语言和呈现的变化原因不同。组件表达信息关系，不能因风格偏好而改写；设计语言需要整套一致，不能每页换一套品牌性格；呈现需要随内容密度和证据类型变化，不能被单一模板锁死。把三者拆开后，可以重组已有能力、吸收外部项目的通用方法，并在不复制模板的前提下扩展。

自由组合仍需质量边界。注册表为“组件 × 呈现 × 载体”标明 `core / adapted / unsupported`，并计算抑制项与降级；例如 table 自身已经以规则线组织信息时，必须抑制背景网格，避免线条叠加。核心能力同时具备 HTML 和可编辑 `.pptx`，适配能力明示降级，不支持组合在生成前停止。

## 原型与选择

用户没有锁定成熟 preset 时，Agent 根据真实内容、受众、场景、密度、素材和目标载体推荐 2～3 组结构上有差异的组合。原型至少覆盖封面、可见文字最密页、首个数据或素材页；用户可以整组选中或跨候选混合，但混合结果必须先生成并确认合并原型，才能批量生成全套。点名已验证 preset 或明确要求快速生成时可以跳过，visual-plan 必须记录原因。

## 中文排版

中文标题和关键文案能在一行容纳时保持一行；必须换行时只在词语或语义短语边界断开，不拆术语、专名、英文词、数字与单位，也不留下标点孤儿或一两个字尾行。HTML 与 PPTX 共享短语提示，并以最终载体截图验收，而不是按字符数猜测。

## 考虑过的备选

**继续追加命名风格。** 否决：会把组件、语言和呈现粘成模板，组合能力和维护边界都不可见。

**把所有轴自由相乘。** 否决：并非所有呈现适配所有组件和载体，装饰也会与组件自身结构冲突。

**只用 HTML 原型代表 PPTX。** 否决：HTML 可快速比较方向，但 PPTX 的字体度量、原生图表和文本框换行不同；目标为 PPTX 时，锁定前仍需真实 PPTX 代表页截图。

## 与既有决策的关系

本决策取代 0012 的视觉系统分法，但保留其独立实现与不复制外部代码、模板或资产的边界；0011 的双载体入口、来源与 notice 合同继续有效。
