# 独立多令牌视觉系统

`507-ppt` 将从双风格样例扩展为由页面组件、配色、字体、形状与密度令牌组成的完整视觉系统；每项公开能力同时覆盖 HTML 与可编辑 `.pptx`，可按载体做效果降级但保持内容映射与风格辨识。实现独立于 oil-ppt，只借鉴其可验证的组件建模与质量审计思路，不复制其代码、模板或资产。

这比仅追加模板更能控制组合爆炸与跨载体一致性；也避免把外部项目变成运行依赖或长期派生维护负担。

## 状态

已由 [0018：视觉幻灯片采用三轴组合与分级载体支持](0018-视觉幻灯片采用三轴组合与分级载体支持.md) 取代。0012 保留“独立实现、不复制外部代码或资产”的来源边界；其中把组件、颜色、字体、形状和密度都视作平级令牌的系统分法，不再是当前视觉建模合同。
