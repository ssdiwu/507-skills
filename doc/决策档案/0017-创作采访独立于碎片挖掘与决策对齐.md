# 创作采访独立于碎片挖掘与决策对齐

项目决定在 `write/` 新增独立的 `507-prospect`，作为可跳过的作者材料生成入口。它通过非诱导、按 material frontier（材料可问边界）自适应成组的采访，显化作者尚未充分表达的亲历、行动、反馈、判断变化、反例与边界：同一材料单元优先连续叙述，从彼此独立的缺口中每轮只取信息增益最高的 2～3 个集中询问，依赖上一答时才逐题。默认只在会话中产出作者材料交接；不核实外部事实，不直接落碎片、产候选创意、确认中心判断或写正文。

不把该动作合入 `507-mine`：`prospect` 负责让尚在作者脑中的材料被表达，`mine` 负责判断、去重、互链和持久化已经表达的材料。两者合并会把材料生成与长期收录判断绑在一起，并使一次口述被误当成必须落盘的碎片。

也不复用 `507-grill`：`prospect` 问“作者如何叙述亲历并形成判断”，必须避免候选与推荐锚定；`grill` 问“在已知前提下用户最终选择什么”，需要给出真实候选与推荐。两者可以共享 frontier 与独立问题批量收集机制；边界不取决于单问还是批量，而取决于问题所有权、问题形态、完成信号与产物。

名称采用 `prospect` 延续写作主链的冶金隐喻，表示在 `mine` 之前探明材料所在；公开中文标题固定为“创作采访”，触发条件依赖“采访作者、问出经历”等明确意图，不使用裸 `prospect`、销售语境、趋势预测或“探索”作为通用触发。代价是多一个可选入口和接力合同，收益是保住作者表达的来源身份，并避免 `mine` 与 `grill` 的职责被采访流程侵占。
