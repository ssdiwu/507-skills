# 小红书图文采用三轴视觉与单一 DOM 分页运行时

`507-rednote` 以“语义组件 × 设计语言 × 视觉呈现”组织视觉决定，并由一个本地浏览器 runtime 同时承担动态预览、真实 DOM 分页与静态导出。`content.md` 和 `visual-plan.json` 是可编辑输入，`paged-content.json` 是绑定输入、字体、素材与 runtime 哈希的编译产物；物理页面不再由 Agent 手写。

这一决定取代文章模式使用 1440×2400 正文、手写 `pages/blocks`、平铺 `visualSystem / themePreset / layout` 以及预览与导出分离的实现合同。所有小红书页面统一为 1500×2000 的 3:4 画布。文章模式仍以文章为内容单位，三轴视觉呈现绑定语义组件而非物理页；视觉摘要才允许页面成为语义单元。

代价是 runtime、文件桥接、分页证据和迁移验证的实现复杂度增加；收益是文字与组件不再被两套布局裁切，动态工作台与直出状态可追溯，视觉系统可扩展而不退化成模板堆。RedNoteImage 只作为产品形状与失败样例；运行代码、依赖和资产须在本仓库独立实现并遵守来源合同。
