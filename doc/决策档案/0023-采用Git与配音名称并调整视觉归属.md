# 采用 Git 与配音名称并调整视觉归属

2026-10-07 用户确认采用 `507-git`、保留 `507-ppt`、采用 `507-voiceover`，并将 `507-taste` 移入 common。本决定落实 [0022](0022-保留职责分组与创作命名.md) 留待取舍的命名与归属建议；forge 的创作命名和三种成文方法继续保留。

| 原位置与名称 | 当前承接 | 边界 |
| --- | --- | --- |
| code/507-release | code/507-git | 已授权的本地提交、信息草稿、引用与关联版本交付；新领域名称不取得任意 Git 操作权限 |
| write/507-narrate | write/507-voiceover | 既有授权声音档案到实际音频与真实时长清单；不写旁白、创建声音身份或制作视频 |
| code/507-taste | common/507-taste | 跨产品、品牌与内容的视觉方向方法；名字与方法不变，不成为所有任务的必经步骤 |
| write/507-ppt | 原位置与名称 | 继续输出已确认内容的 PPTX 或 HTML 幻灯片，未采纳 slides 候选名 |

三个职责域为 common 7 项、code 10 项、write 11 项，总计 28 个活动入口。公开名字、目录定位与产物范围保持一致，所有 Git 外部动作、声音授权和审美选择仍按既有合同执行。

## 接口与恢复

仅更换公开技能名和相应包路径；不保留重复活动别名。配音的客户端请求标识 `507-narrate`、`voicebox_narrate.py` 和 `narration-manifest.json` 是现有协议／实现名字，保持原样；它们不产生第二技能，也不成为新能力的授权。

在包含前序 forge 改稿的实际工作树快照上建立隔离候选，核对资源、调用、路径与独立使用，再切换已识别消费者。只迁移实际存在的本机入口，不重新激活已停用配置；未知外部安装与真实宿主加载另行报告。历史快照保留当时名称，旧路径审计链接固定到其记录提交，当前导航使用本决定的新入口。

相关验证与独立审查见[迁移记录](../40-版本实施方案/确认命名迁移验证.json)。提交、推送和发布没有包含在命名与归属授权中。
