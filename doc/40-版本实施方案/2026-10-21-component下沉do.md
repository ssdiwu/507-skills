# component 下沉为 do 包内方法

本批按已确认的最小范围，将产品界面组件能力移入 do 的包内专用方法，退出独立活动入口。目的是让已持有工程目标与操作范围的 do 直接处理，减少为同一任务再次交接；没有新增共有规则、调度工具或宿主配置。

## 能力与去向

| 原能力 | 当前承接与边界 |
| --- | --- |
| 只查产品组件 | do 的请求范围表明确只交位置、适用性和未知，不修改组件、调用、依赖或库配置 |
| 复用已有组件 | 已知可用直接采用，不重走查找或完整工程准备；需要核实时按实际导出、参数、状态和调用判断 |
| 抽取并迁移 | 库内没有适用组件，且同语义界面块有多个已存在或已确认使用位置时才抽取，迁移范围内已写调用；单处留在原地，不编造未来消费者 |
| 行为与操作范围 | 保留原授权、行为基线、回调与状态所有权，以及真实页面和原动作验证；不安装新库、不重做设计系统或改变业务权限、数据通路 |

当前合同见[do主文](../../next/skills/507-do/SKILL.md)与[组件方法](../../next/skills/507-do/references/component-reuse.md)。专用方法保留原方法正文，仅调整包内链接、只查找的产物表述及退出旧入口后的返回表述；原入口最低合同保留在 do 主文。

## 旧入口与维护

[原六文件包](../90-归档/技能/507-component/SKILL.md)完整保留归档字节；原[组件实施与验证](2026-10-14-产品组件入口实施与验证.md)及其他首次证据不回改。旧名507-component登记为退役并映射到do，不保留活动空壳。包装清单与打包器退出旧身份，四项共有方法移除旧消费者，已有do消费者及共有正文保持；生成索引同步四个真实消费者。

当前清单为18入口（10主要、8次要），58件自有文件及196件共有副本，共254件。AGENTS、其他技能正文和原停止事项不因本批改变。

## 验证与限制

打包同步、精确清单检查与不可变包构建通过；32项现有打包测试通过。独立位置中的旧名查询只返回do，操作授权保持且运行可用性不作推定；原六文件归档逐字一致，受影响文档215个相对链接可解析。源码独审通过后完成实际安装：修改do主文及四份索引、新增一份组件方法，原活动入口六件备份并移出；18入口254件与已审固定包逐字一致，另9件MiniMax私有review保持。已核1859个范围外安装文件／链接对象未变。安装与两份状态文档增量独审通过；本批按授权本地提交，不推送，具体提交以Git记录为准。

本批不运行自然选择、模型或真实产品任务，不新增环境；源文件、打包或安装一致不证明模型读全、采用正确、实际页面可用或效率收益。旧MiniMax漏选及提醒对照限制继续保留，不以本次结构调整宣称解决。仅本地提交，不推送。
