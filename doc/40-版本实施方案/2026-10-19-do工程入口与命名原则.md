# do 工程入口与主要技能命名

本批按已确认方案直接在 main 建立主要入口 [507-do](../../next/skills/507-do/SKILL.md)，承接 implement 的工程实现和测试限定，以及 fix 的修复方法。用户主要通过主要技能表达目标，Agent 按需采用主次技能；名称“执行”对应工程范围，未扩大为所有领域的通用执行器。其他技能的职责调整不在本批。

## 四类请求与直接进入

| 请求 | 已有条件与具体做法 | 结束位置 |
| --- | --- | --- |
| 新增功能 | 沿用已确认需求、方案、指定版本和范围，直接实现；只补影响当前动作的真实缺口 | 约定行为及必要验证完成；相关变化按要求独审 |
| 修 bug | 进入修复模式，保留可信失败信号、根因、最小修复和同一原动作复验 | 原故障与受影响路径的实际结果明确，首次失败与修订分开 |
| 局部修改 | 保持指定修改范围；属于故障仍保留完整修复步骤，行为变化与行为不变分别处理 | 指定变化和必要相邻检查完成，不扩大为整项目重构 |
| 只跑测试 | 运行约定检查并分类报告，不自动修改生产代码、断言或持久配置 | 实际结果、失败原因与未覆盖清楚，不由失败取得修复权 |

补测试、测试先行和只写失败测试继续沿原 [testing](../../next/skills/507-do/references/testing.md) 保留各自范围。新增功能不要求先制造旧故障；已有充分方案不重走采访、规划、规格或工单全链。
